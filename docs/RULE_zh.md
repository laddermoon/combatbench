# CombatBench 规则 V1.0（纯血条极简版）
 
## 一、任务目标
 
控制双足机器人，通过有效打击减少对方血量，先将对方血量降至 0 者获胜。
不判断倒地、不读秒、不设犯规、不干预姿态，一切由血量决定胜负。
 
## 二、胜负规则
 
1. **双方初始血量**：100 点
2. **获胜条件**：
   - 2.1 将对方血量先降至 0，则比赛立即结束，KO获胜。
   - 2.2 在比赛时间结束时，血量更高者获胜。
   - 2.3 时间结束血量相同：判定为平局。
3. **比赛时长**：每个回合时长 30 秒，进行 6 个回合。
4. **重置状态**：每个回合开始时，都会从初始位置开始（两个机器人距离两米远相向而立），不论上一局结束时是什么状态。
 
## 三、有效打击判定（唯一掉血逻辑）
 
### 1. 允许的攻击部位（打击方）
 
仅以下部位发动的攻击可造成伤害：
- 手（hand）
- 前臂（lower arm）
- 上臂（upper arm）
- 脚（foot）
- 小腿（shin）
- 大腿（thigh）
 
**注意**：躯干、头部均不能作为有效攻击部位。使用躯干和头部击中对方，对方不掉血。
 
### 2. 有效受击部位（被打击方）
 
仅以下部位被击中会掉血：
- 头部（head）
- 躯干（torso，含胸、腹、腰上部、腰下部）
 
其它部位被击中一律不掉血。
 
### 3. 物理条件（力阈值判定）

伤害在每个物理子步（500Hz，dt=0.002s）实时结算。伤害公式为：

```
damage = part_weight × (force / force_scale)² × dt
```

其中：
- `force`：该物理子步中碰撞接触的法向力（N）
- `force_scale`：力阈值参数，默认 100N
- `dt`：物理步长，0.002s
- `part_weight`：部位权重，头部 3.0，躯干 1.0

`(force / force_scale)²` 项构成二次阈值：
- 力低于 100N 时伤害被抑制（如 50N → 0.25×，几乎不掉血）
- 力等于 100N 时为阈值点（1.0×）
- 力远高于 100N 时伤害被放大（如 200N → 4.0×，400N → 16.0×）

这意味着轻碰、慢推、持续贴合产生的低力接触几乎不造成伤害，而高速重击会造成显著伤害。

### 4. 伤害数值

伤害不是固定值，而是由上述公式连续计算。参考量级（force_scale=100N, dt=0.002s）：

| 碰撞力 | 头部单子步伤害 | 躯干单子步伤害 |
|--------|---------------|---------------|
| 50N    | 0.00075       | 0.00025       |
| 100N   | 0.006         | 0.002         |
| 500N   | 0.15          | 0.05          |
| 1000N  | 0.6           | 0.2           |

一个持续 50ms（25 个子步）的 1000N 击打，对头部累计造成约 15 HP 伤害，对躯干约 5 HP 伤害。

*头部权重是躯干的 3 倍，因此相同力下头部受到的伤害始终为躯干的 3 倍。*

## 四、姿态与行为规则（全部不限制）
 
以下行为均不判负、不扣分、不惩罚、不重置：
- 倒地、翻滚、地面进攻、地面防守。
- 缠抱、贴近、压制、拉拽。
- 用头撞击、用躯干顶撞（不掉血，但允许发生）。
- 任何姿态、任何移动方式。
 
AI 可自由演化最优策略，不需要模仿人类格斗。
 
## 五、物理与执行规则
 
1. **物理步长**：固定 500Hz，保证物理一致性。
2. **策略决策频率**：20Hz（每 50 毫秒一步）。
3. **超时行为**：超期未输出动作则自动保持上一动作。
4. **公平性**：全局物理参数、模型参数对双方完全一致，保证绝对公平。
