# Humanoid28 观测空间（110 维）

结构参照 humanoid21 四模块（决策 #3），本体部分为原始弧度值无压缩
（用户拍板：与 MimicKit `dof_pos/dof_vel` 语义一致），root/足力/对手模块
按 humanoid21 惯例（含少量 sign·sqrt 变换维度）。

## 设计要点

1. **本体 56 维全是原始物理值**（决策 #3 字面落地）。关节速度可达几十
   rad/s，训练侧如需归一化请在策略/特征层自行处理，环境不做。
2. root 语义是 **pelvis**（不是 humanoid21 的 torso）——高度、速度数值
   分布不同，不要直接套用 humanoid21 的统计量。
3. `sqrt` 变换公式：角速度 `sign(w)·√(|w|/2)`；对手四肢速度
   `sign(v)·√(|v|)/2`。与 humanoid21 相同。
4. 向量类量全部在 ego/机体系表示，避免绝对世界坐标过拟合；例外：
   pelvis 高度（标量）与足底力（标量）。
5. step 系实验若叠加 gait clock 等附加维度，在策略/实验层拼接，
   环境基础观测恒为 110 维。
