## 特征（67d/帧 @20Hz，转换窗 150ms=3 控制帧）

关节角（限位归一化 21）+ 关节角速度×0.1（21）+ 根高（1）
+ 根线速度→yaw 对齐系（3）+ 根角速度→yaw 对齐系（3）
+ 6 关键点相对骨盆→yaw 对齐系（18）。与观测空间同一哲学：
xy/yaw 不变，风格分只描述"怎么动"不描述"在哪动"。

**窗长是验收级决策**：单步 50ms 的真实位移增量（归一化 ~0.01）
与冻结负例（增量恰 0）无分辨余量；150ms 下真实增量 0.1–0.3。

## 负例语义修正（v1→v4 关键教训）

初版把"冻结/倒放"对全部转换合成 → 判别器学不会（frozen D≈real）。
原因：**静止/近对称慢速段在参考库中是真实分布**（站立间隙、坐姿
起始）。按 README §10"按动作类别判断"修正为**只取动态段**
（增量幅度 top50%）合成 frozen/reversed 负例——"运动中途定住"、
"出拳收放时序反演"才是离分布。

## 压力测试（disc_v4，D∈[0,1]）

| 类 | D_mean | p05 | 判定 |
|---|---|---|---|
| real（训练内） | 0.79 | 0.52 | — |
| real（低分 clip 17_10） | 0.62 | 0.24 | — |
| frozen（动态段定住） | 0.38 | 0.03 | ✓ |
| reversed（动态段倒放） | 0.34 | 0.01 | ✓ |
| shuffle（瞬移/过渡缺失） | 0.27 | 0.02 | ✓ |
| speed（速度通道×2.5） | 0.32 | 0.01 | ✓ |
| jitter（关节加噪） | 0.06 | 0.00 | ✓ |
| random（限位内随机游走） | 0.00 | 0.00 | ✓ |
| repeat（转换循环） | 0.62 | 0.17 | ⚠ 见下 |

**在线验证**（observer 接真实环境）：track_walk u02000 策略回放
D=0.70、track_box u1898 回放 D=0.79（物理真实的跟踪动作→高分✓）；
随机动作（8 步摔倒）D=0.22 ✓。

## 已知边界

1. **repeat 不敏感**（0.62）：机械循环与自然步态循环在 150ms
   窗内本质相近，区分需要更长时序——留给序列判别器/长窗版本。
   用户关注的"机械重复"若重现，应升级窗长而非提高权重。
2. **微颤不敏感**：u1898 的可见小颤动 D 仍 0.79——合成 jitter
   负例幅度（σ=0.35）大于策略实际颤动。若要压制该缺陷，负例
   需加入真实策略 rollout 的颤动样本（M4 在线对抗训练自然覆盖）。
3. **负例是合成的**：真正的 AMP 闭环是"当前策略数据作负例"持续
   训练；本版证明特征/接口/判别能力成立，不承诺冻结通用
   （README §7.2 边界一致）。
4. in-place 循环按坐标不变性**设计上不可检出**——"在哪动"被
   刻意消去；若任务需要，由任务奖励/根跟踪项处理，不属于本
   判别器职责。
