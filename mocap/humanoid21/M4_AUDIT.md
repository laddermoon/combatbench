# M4 审计 —— 先验受控 A/B 实验（reach-center）

日期：2026-10-14。README §9 M4：无先验 vs 有先验的受控小任务对照，
回答"风格先验在任务学习中是否有用"。

## 实验设计

任务 `reach_center`（`exp_reach_center.py` + `reach_center_env.yaml`）：
robot_a 站立出生在环形场地边缘（半径 1.5–2.5m，方向经
`RotateSpawnPlugin` 随机到整圆，始终面朝中心），须**直立**走到
|xy|<0.8m（`reach_done`）；跌倒 `reach_fall`；10s 超时。
目标方向由既有 `arena_center_local` 观测提供，**观测零改动**。

两臂/三臂共用同一 env、observer、网络、episode 预算；唯一差异 =
`r_style` 通道的 actor_weight（0 / 0.25 / 0.5）。先验 = 冻结
`disc_v4`（本版未做在线对抗重训——M4 先隔离"风格信号本身"的效应）。

r_task = progress(×20) + 10·done − 10·fall + 0.02·step。
r_style = −ln(1−D)，恒记录（两臂可比），仅 actor 优势按权重注入。

## 过程修正（如实记录）

| 版本 | 问题 | 修复 |
|---|---|---|
| v1 | 出生距离 [4,10]m，r≥3.4m 撞墙被**弹出到场心**（reach_rate 0.8 是假象） | 场地半径 3.38 → dist[3,5] + 随机转角 |
| v2 | **dive-and-tag**：扑向目标，倒地前 xy 达标即算成功 | done 需 z>0.9 直立 |
| v3 | 门控后仍潜水：progress 已支付 ~95%，倒下近似无成本 | r_task 加摔倒端点惩罚 −10 |

## u800 结果（eval 32 episode，±~0.15 噪声）

| 臂 | reach_rate | fall_rate | D_mean | mean_steps |
|---|---|---|---|---|
| w0（无先验） | 0.59 | 0.41 | **0.10** | 23 |
| w0.25 | 0.53 | 0.47 | **0.85** | 34 |
| w0.5 | ~0.5 | ~0.5 | **0.87** | 50 |

- **任务指标不降**（噪声内），**风格分 8 倍差距**，且方向单调于权重。
- 视觉抽查：w0 用大开大合劈叉式弓步弹跳；w0.25 直立双腿交替步进。
  判别器低分与肉眼"不正常"一致——先验压住的正是退化运动。
- 代价：先验臂更慢（34–50 步 vs 23 步）——走路本来就比扑跳慢；
  摔倒率未降——风格奖励≠平衡技能，平衡仍是主要瓶颈。

## 结论与边界

**先验在此任务上有用**：同等任务成功率下产出显著更像人的运动。
按 README"动作质量明显改善且任务效果不明显下降"判 M4 通过。

边界（不外推）：
- 单任务、短程、单种子基——结论限于"风格塑形可行"，非"先验
  加速学习"或"先验提高成功率"；后者需要多任务多种子。
- 判别器冻结：在线 AMP（策略数据作负例持续训练）未做，属后续。
- w0.5 收敛明显变慢——任务权重较大时风格压力是负担；实际接入
  建议 w_style ∈ [0.2, 0.3] 起步并随任务收敛度衰减。
- repeat/微颤盲点在任务中未暴露明显副作用（两臂均未见静止钻分）。
