# DynaBPTT 主实验决策清单（v2 定稿草案，待用户确认）

> 本文档回答框架 8 问，取代 DYNABPTT_FRAMEWORK.md 中的 Balance 实例化决策。
> 原则：尽量不带随机；数据无噪声无冲突 → 拟合不了就是模型问题；一个实验做透。

## 八问答案

### 1. Policy 网络定义
- `TruncatedNormalPolicy` MLP(96→256×2→21)，取 deterministic_action 作为策略输出
- log_std 不使用、不训练、不进 BPTT 图
- 外部噪声仅在 SubStartSet 补足阶段使用（见 4），稳态下策略完全确定性

### 2. WM 网络定义（rep 路线，已拍板）
- **WMState = (aux 7, rep 52, feet 2)**——rep/aux 由 cs 解析变换，
  feet = obs[52:54] 作为**普通状态维**放进状态，由转移模型一并
  回归（不是学习头；拟合不准就不准，可接受）
- F = `dyn` MLP(54+21 → 1024³ → 29) 预测
  [Δv_b, Δw_b, Δvj, Δfeet]；位姿/关节走解析积分，feet 直接加 delta
- 三个映射：
  EnvState→WMState = represent/extract_aux + obs[52:54] 切片
  WMState→Observation = compose_obs(rep, aux, feet) 解析
  WMState→Loss = analytic_phi(rep) 解析
- **判据 = 1-step Bryson 归一化误差 < 1.0**：rep_pred vs rep_env
  在 loss_blocks 的四个块（root_pos/root_ori/joint_pos/joint_vel）
  上按 NOMINAL_ERRORS 归一的均方误差；1.0 = 误差在物理容忍度内。
  feet 不进判据（物理上承认不可精确回归，仍进 loss）
- 判据与 φ 完全无关——WM 只负责 rep 对 rep 的回归质量
- 已证伪：全 WMState 全局 nRMSE<0.01 够不着——离线死训地板
  ~0.9（接触混沌致 vj 不可约误差），若坚持会让策略永不更新

**已证伪的路线（留档）**：WMState=obs(57) 的 obs→obs 回归存在
不可约误差地板——feet_forces 由不可见接触状态决定（rmse≈std，
解释力≈0），jv/角速度维度的 sqrt 压缩在零附近放大误差。
实测 nrmse 0.5+ 收敛不动，而 paired φ-MAE 仅 0.002。

**势函数 φ 与 WM 完全无关**：φ 是状态的解析函数
（uprightness×z/standing_height），对 Env 产出的真实状态和 WM 产出
的想象状态一视同仁地计算——不学习、不 clamp、不是 WM 的头。
StartSet 中每个状态的 φ 权重、想象损失 J、诊断信号，用的都是这
同一个解析 φ。

### 3. Init StartSet
- `{standup}` 单状态，φ=1

### 4. StartSet 更新 + SubStartSet 采样
- **Episode 数：每 update 2048 个分支 rollout，每个 NStep=8 步**
- **准入：严格 s₁ 唯一入集**；后 7 步只作 WM 数据 + 配对校验 + 种子可行性证据
- **无 cap、无去重**：所有 s₁ 无条件入集，集合只增不减
- SubStartSet 构成：
  - `|StartSet| < 2048`：全部元素各跑一次**确定性** rollout；
    再抽取元素跑**带噪** rollout（σ=0.15）补足到 2048
    ——噪声仅存在于补期阶段，作用是数据多样性（确定性重复无信息）
  - `|StartSet| ≥ 2048`：抽取 2048 个，全部**确定性** rollout
- 抽取分布：**统一 φ⁶ 加权**（无均匀地板），所有抽样场景同一规则
- **想象与 rollout 共用同一 SubStartSet**（2048 种子）

### 5. ReplayBuffer → WM 采样
- Buffer 为**只增不减**的全量历史：每 update 新增 2048 条 8 步窗口，无淘汰
- 每次拟合数据 = **本次 update 产生的全部窗口**（必用）
  + **历史窗口按更新代数 recency 加权采样**：`w = exp(-age/τ)`，
    τ=100 update（可调）；不归一即按概率抽
- 拟合是**收敛循环**而非固定批数：训到回归误差达标为止（见 6），
  批数上限 2000 批×256（安全阀；触发上限 = 上报"模型容量/结构问题"）

### 6. WM 误差门槛
- **WM 的语义 = 本批数据的可微重放，不要求泛化性**。想象的有效性
  不靠模型泛化保证，而靠"想象查询始终落在已拟合的数据分布内"保证
  ——覆盖问题由 StartSet/SubStartSet 机制管，不归 WM 管
- **判据 = 本 update 新窗口上的回归误差**（与 φ 无关，无留出集）：
  单步 next-state 归一化 RMSE（每维按 buffer 标准差归一）**< 0.01（1%）**
- **新窗口既是训练集也是测试集**；历史数据只进训练集，
  作用仅是补数据/防遗忘，不参与判据
- 数据确定性、无冲突 → 必然可拟合；拟合不到=模型容量/结构问题，持续训练
- **门控语义 = 收敛性前置**：WM 未达标前不 Imagine、不更新策略，
  只采集+拟合（达标是策略更新的前置条件，不是事后否决）
- 达标后每 update 继续拟合（本轮新数据必进），维持达标状态
- 配对闭环 φ-MAE、覆盖率等降为**诊断信号**（记录、告警、不归入门控否决）

### 7. S5 Loss(I)
- **`J = Σ_{t=1..8} φ(ŝ_t)`**，纯势函数求和，越大越好
- 无 critic、无 bootstrap、无 done 塑形权重、无 discount（γ=1）
- 想象动作 = 确定性策略输出；想象内不加动作噪声、不加 obs 抖动
- feet 通道想象时置零（WM 的 feet 头不参与想象）

### 8. S6 epoch 数
- 4 个梯度步/update，同一批想象数据复用
- actor lr 1e-4；WM lr 3e-4（沿用既有值）

## 我推演出来的后果，需要你确认

### Q1（坑）：无去重 + 确定性 rollout = 精确重复累积
确定性策略下，同一种子的 s₁ 每次 rollout 完全相同。
`|SS|<2048` 时每轮全量重跑 → 老状态的后继每轮重复入集一份，
StartSet 变成"路径 + 多重计数"结构：深度为 d 的状态多重数 ≈ 已跑轮数−d。
采样实际权重 = φ⁶ × 多重数。**这不是 bug 但会改变采样语义**——
老状态天然获得高多重数。若这不是你要的，需要恢复去重或按状态身份合并计数。

### Q2（坑）：确定性波前 = 一条链而非一片前沿
严格 s₁ 准入 + 确定性 rollout 意味着从 standup 出发，前沿每轮沿
确定性轨迹只推进 1 步（s₁→s₂→s₃…是一条链）。多样性完全来自
补期阶段的带噪 rollout 撒点。集合到 2048 之后噪声停止，
前沿变成纯确定性流——**StartSet 收敛为"当前策略确定性轨迹的可达集"**。
这是自洽的（框架本来就是"沿策略轨迹推进"），但值得明确知道：
集合不再"探索"，只记录"策略实际走到哪"。

### Q3：~~φ⁶ 加权采样是否保留~~（已定）
统一 φ⁶ 加权、无地板，补期阶段的重采样也按同一加权规则。

### Q4：收敛判据的初始阈值 0.01 是拍的
"设的比较小"我落到 1% 归一化 RMSE。首轮跑完可拿实测收敛水平校准；
若 WM 很快到 0.1% 量级，门槛应收紧到 0.002 这类。

### Q5：无 anchor 机制
早期方案里的 anchor-slots 取消——|SS|<2048 阶段 standup 每轮自然全量
参与，稳态后它 φ=1 权重足够。如果你认为部署锚点需要独立保证，说一声。

## 不变的部分（沿用上轮已验证的修复）
- φ 不 clamp（clamp 是 bug，不在任何 spec 里）
- 部署 eval（自然初始状态完整 episode）作为唯一诚实判决指标
- JSONL 诊断每 update 输出：wm 回归误差曲线、配对 φ-MAE、覆盖率、
  StartSet φ 分布、J、gnorm、前沿推进速度
