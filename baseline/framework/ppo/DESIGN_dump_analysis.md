# Dump 分析工具：功能产品方案

## 1. 定位

Dump 是一次 PPO update 的分析工作台，不是文件浏览器，也不是另一套训练监控。

- Run Dashboard：定位训练在哪一轮发生变化。
- Dump：检查这一轮的训练信号、梯度和更新过程，找到具体证据。
- Resume + 干预实验：验证原因。单个 Dump 不直接证明因果。

核心使用路径：**总览发现现象 → 筛选样本或步骤 → 下钻来源 → 形成可验证的解释**。

## 2. 主要能力

| 能力 | 回答的问题 | 主要功能 |
|---|---|---|
| 截面总览 | 这一轮发生了什么，先看哪里？ | 采样规模、ADV 概况、梯度概况、Actor 更新量、早停位置；少量事实提示及证据入口 |
| 训练信号 | Actor 实际用了什么信号？ | Reward / Value / Raw ADV / Normalized ADV / Combined ADV 的分布与变换；通道权重、confidence、缩尾影响 |
| 梯度分析 | 哪些样本推动或抵消聚合方向？ | 梯度范数 × cosine 分布；正负投影、贡献集中度；极值样本排名与 Episode 分组 |
| 更新过程 | 梯度最后变成了怎样的更新？ | minibatch 的 loss、梯度、实际参数位移、KL 检查及早停；关键步骤前后对照；epoch 末 ratio / value 变化 |
| 样本溯源 | 统计现象对应什么行为？ | 从 buffer index 关联 trajectory、Episode、agent、frame；复用现有轨迹详情与按需画面回放 |

所有能力优先使用已采集的数据，不新增常规训练开销。缺失字段显示不可用，不补零、不猜测。

## 3. 前端呈现

Dump 默认进入总览，而不是 Episode 列表。

页面导航：**总览 / 训练信号 / 梯度信号 / 更新过程 / 样本**。

总览只保留：

1. Run、update、捕获来源及数据完整性。
2. 采样、信号、梯度、更新结果的核心摘要。
3. 少量“值得检查”的事实提示，每条都可下钻。
4. 梯度分布、更新时间线缩略图及重点样本入口。

统一交互：

- 点现象查看证据，点图中区域筛选样本，点样本进入轨迹或画面。
- 样本表支持排序、少量常用筛选及按 Episode 分组。
- 返回时保留筛选条件；当前分析位置可通过链接分享。
- 图表解释说明指标定义、统计范围、采集时点及不能推出的结论。

Episode 列表保留为样本浏览入口。复用现有详情页，不另造一套查看器。

## 4. 向 AI 提供相同能力

前端与 AI 共用分析函数：

```text
已有 Dump 文件 → 共享分析层 → HTTP / 前端
                         → debug.py / JSON
```

建议增加四类离线查询，命名在实现时确定：

- `inspect`：数据能力、核心摘要、事实提示及下钻入口。
- `distribution`：字段分布、分位数、有效数量。
- `samples`：筛选、排序、分组和有限数量的样本结果。
- `trace`：指定样本的训练信号、梯度诊断、epoch 变化及环境来源。

补齐 Timeline 的离线步骤查询，以及已采集但尚未通过 API 暴露的参数位移等字段。

返回数据统一携带：指标定义、采集时点、全量/抽样范围、有效与缺失数量、证据索引、解读限制。默认返回摘要和 Top-K，不输出全部数组。

前端提供“复制分析上下文”：包含 Dump 位置、筛选条件和查询入口。首版不内置模型调用。

## 5. 必须守住的语义

- 聚合梯度 G 来自全 buffer；逐帧梯度诊断最多抽样 2000 帧。样本排名和集中度必须标为抽样统计。
- 梯度诊断位于更新前的 θ_old，不等于 Adam 执行后的实际更新方向。
- 负投影表示与聚合方向相反，不代表坏样本或任务收益下降。正负贡献分开统计，避免用接近零的净值作分母。
- 不同指标标明更新前/后、epoch/minibatch 等时点，不能把同一行的数字直接解释成因果链。
- 未抽样、零梯度、方向未定义、文件缺失、溯源失败是不同状态。
- 事实提示仅陈述可核验现象，不自动宣称找到训练失败原因。

## 6. 首版范围与验收

首版优先打通一条完整分析链：

1. 总览与数据完整性。
2. 梯度分布、正负投影排名、样本溯源。
3. 更新时间线关键步骤入口，补齐已有字段的读取。
4. 前端与 AI 共用的摘要、样本查询和追踪能力。

验收：打开一个 Dump，人和 AI 都能知道是否早停、在哪一步停止；找到强梯度或强反向投影样本；追到其训练信号与 Episode；所有结论能指向证据。旧 Dump 缺数据时正常降级。

后续再做 ADV 变换对照、跨视图筛选联动和 Dump 对比。Dump 对比只有在样本身份一致时做逐帧差值，否则只比较分布。

不做通用报表编辑器、任意公式系统、自动因果诊断或另一套采集管线。
