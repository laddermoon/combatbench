## 1. 实验设计

### 1.1 目的

验证"参考策略位移 Δ = μ_current − a_ref"是否为可复用的探索信号，回答三个问题：

1. Δ 有多大（幅度与训练阶段的函数关系）？
2. Δ 有没有方向延续性（连续两代位移是否同向）？
3. 若用于 σ 调制（`σ_i = c·|Δ_i|`），参数应取什么量级？

本实验为**纯诊断**（Stage 0）：不改训练行为，只做回放测量。

### 1.2 数据来源

- 源批次：`sweep_uf0`（8 策略 × 3 seed，uncertainty_floor=0，ef=0，600 update）的 **seed 42**
- 每个策略取 6 个阶段：**u10 / u50 / u100 / u200 / u300 / u500**
- 每个 (策略, 阶段) 构造一个诊断 run：从源 run 最近的前置 checkpoint `--resume-from` 续训至目标 update，以 `--dump-at` 捕获该 update 的 dump，软链源 run 的 `policy_exports/u1..u{target}`，然后 `debug.py delta --gens 10` 对 **3 个 episode × 2 个 trained agent** 做确定性回放
- 合计 48 诊断 run，0 失败；每格 ~6 个 agent-episode 样本（每 episode 200 帧）

### 1.3 Δ 定义与指标

对 dump 中存储的 obs（T 帧），以 `policy_exports/u{U-g}`（g=0..10）逐帧跑确定性 `act()`：

- `Δ_g(t) = a_u(t) − a_{u-g}(t)`，均为确定性动作（21 维）
- `‖Δ_g‖`：对帧/episode/agent 取均值——主指标
- `cos(Δ₁, Δ₂)`：连续两代单步位移的逐帧 cosine——方向延续性
- 累积比 `‖Δ₁₀‖/‖Δ₁‖`：独立噪声基准 √10 ≈ 3.16，超此即超扩散
- `|Δ₁|/σ̄`：单步逐维漂移占当前策略 σ̄ 比例——标定用法 1 的 c
- 逐维 `|Δ₁|` 的 HHI（Herfindahl 指数）：维度集中度，均匀基线 1/21 ≈ 0.048

**注意**：MoG 的确定性动作是 **argmax 权重分量的 μ**（`deterministic_action`），非边际均值 Σπᵢμᵢ——logits 接近分界时该投影离散跳变，会人为放大并振荡 Δ（见 §3.4）。

## 3. 结论（分级）

### A 级——可信（48 格一致、机制可解释）

**A1. Δ 信号存在但弱**：单步漂移不为零且逐代位移有净正相关（累积比普遍 >√10），但方向延续性本身弱——即使最强的单分量格 pooled cos 也只有 +0.05~+0.13。Phase-0 的"信号存在性"门槛**通过**，但不支持"强方向信号"的期待。

**A2. 漂移幅度按族分层且 MoG 退火、单分量不退火**：MoG u10 漂移 0.14–0.19 是单分量的 2–3 倍，且随训练 ~3× 单调退火至与单分量汇合；单分量全程 ~0.06 平台，task 收敛后仍以恒定速率游走（策略无不动点）。"Δ→0 自退火"卖点**只对 MoG 成立**；单分量上 `σ=c|Δ|` ≈ 恒定比例调制。

**A3. 标定结论明确**：上一代参考（g=1）下 `σ=c·|Δ|` 需要 **c≈10–30** 才能与当前 σ̄ 可比；EMA/十代视野的参考下 **c≈5–7**。参考策略必须取 EMA/多代而非上一代——TODO 的原始建议被数据坐实。

**A4. 漂移各向同性**：21 维上漂移均匀分布，"某关节组主导漂移"不存在。逐维 σ 调制可用，但收益不来自维度选择性。

**A5. 方向延续性按族分裂**：单分量 pooled cos +0.05~+0.13（60–68% 帧正向）；MoG pooled cos ≈0 或负（45–61%）。MoG 的大漂移里**振荡成分占主导**。

### B 级——线索（机制合理，证据或量级待验）

**B1. MoG 漂移部分来自确定性投影伪影**：`deterministic_action` 取 argmax 分量 μ——logits 近分界时确定性动作离散跳变，单步 Δ 被放大且连续两代跳变方向易反号。这同时解释了 A2（MoG 漂移大）与 A5（MoG cos≈0/负）相当部分，但不必然推翻全部 MoG 漂移——真实参数漂移与模式切换混杂，当前数据无法分离占比。**若 Stage 2 在 MoG 上落地，参考量应改用边际均值 Σπᵢμᵢ 或逐分量处理，而非 argmax 投影**。

**B2. MoG 晚期振荡**：u500 多个 MoG 格 cos 明显转负（−0.19~−0.29）。机制上晚期策略在解附近做模式间往返（或参数在 plateau 上游荡回摆）。含义：EMA 参考的 Δ 在晚期测的是**振荡幅度**而非改进方向——σ 调制语义随阶段切换（早期追方向、晚期探测振荡带宽）。

**B3. ‖Δ_g‖ 随 g 亚线性饱和**：10 代窗口内增长放缓，漂移是有界游走而非持续单向推进——PPO 的参数更新在动作空间的投影存在自然尺度上限。

### C 级——观测记录/限制

- **单 seed（42）× 3 episode × 2 agent 每格**：所有数值是探索性量级估计，跨格小差异（<20%）不可信
- **观测分布近似**：dump 的 obs 来自 resume 后 ~5 update 的短 rollout，接近但不等于原 run 该 update 的精确访问分布；对"幅度量级"结论无碍，对精细阶段比较可能引入几 % 误差
- **Δ 是复合度量**：混合了参数漂移与 obs 分布移动；本报告未分离两者
- **单分量的"恒定游走"**是 u500 仍是 ~0.05 的事实陈述，是否延续到更长训练（>600）未知

## 4. 对 Stage 1/2 的设计含义

| TODO 原始设想 | 数据结论 | 建议 |
|---|---|---|
| 用法 2（均值平移） | 方向延续性太弱（cos≤0.13，MoG≈0），平移≈注入噪声 | **不做**或仅作负对照 |
| 用法 1（σ 调制） | 可行，但 g=1 参考下 c=1 会砍掉 90%+ 探索 | **EMA 参考（horizon≈10 update）+ c≈5**；`σ_i = max(c·|Δ̄_i|, σ_floor)`，参考侧 detach |
| "Δ→0 自退火" | 仅 MoG 呈现退火；单分量 Δ 恒定 | 单分量仍需 uncertainty_floor 托底；Δ-σ 是自适应调制而非退火器 |
| EMA 参考 | 数据支持：十代窗口 Δ/σ≈15–20%，c 取个位数即可 | EMA 而非上一代 |
| MoG 上的 Δ | argmax 投影引入模式切换伪影 | MoG 参考量建议用边际均值 Σπᵢμᵢ；诊断也应补算该口径 |

**Stage 2 建议的首个对照**：`mixture`（Δ 最大、退火最干净）与 `base`（最小漂移基线），EMA 参考 + c≈5，与 floor sweep 互为基线。预期效应：MoG 上 σ 获真实退火调度；单分量上接近常数调制，若见收益则说明"漂移大的维度值得更大探索"这一机制本身有效。
