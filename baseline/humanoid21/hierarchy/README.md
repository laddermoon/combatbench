# Hierarchy — 分层控制大本营（Code-as-Policy + 通用底层执行器）

> 类型：指南

本目录是 `humanoid21` **分层格斗路线（Hierarchical Combat）** 的大本营。

## 1. 核心思想

将原本端到端耦合在一起的“格斗问题”正交解耦为上下两层：

- **上层大脑（High-Level Decision — Code as Policy）**：
  读取平台标准 96 维观测中的几何与运动学信息（对手根部/头部/手脚在机体系下的坐标与速度），用白盒 Python 规则（后续可扩展为 LLM 代码进化或高层轻量 RL）负责战术距离控制、提前量预判、左右手轮换与攻防时机选择，输出 **8 维物理语义组合码（Command Vector）**。
- **下层小脑（Low-Level Executor — Goal-Conditioned Self-Supervised RL）**：
  剥离 39 维对手观测，仅接收 **`57 维本体观测 + 8 维物理语义指令 = 65 维`** 输入，通过单人无对手自训练（Self-Training），掌握在**绝不摔倒**的前提下执行具體动作原语（起身、抗推站稳、全向移动、左右拳三维空间打点、左右脚三维空间踢点）。

## 2. 第一原则：不倒优先（Balance-First Iron Law）

底层模型的训练与运行严格遵守 **“先站稳、再出招；宁可收招，绝不摔倒”** 的最高优先级：

1. **复用 Standup 既有成果**：所有底层模型均从已收敛的 `standup_mbs_ef05_s42`（`u350`）通过无损权重切片暖启动，首先在 65 维新契约下固化起身与抗推平衡能力。
2. **梯度硬门控**：平衡通道（`r_potential`、`r_fall`）全时段无条件在线；任何动作通道（打点、移动）的 `actor_weight` 均受直立度安全门控约束，一旦姿态不稳，动作梯度归零，全力恢复平衡。
3. **指令熔断与一票否决**：未站稳不发招，发招中途失衡立即切回 `STAND`；Eval 倒地率超标对模型保存与课程晋级实行一票否决。
