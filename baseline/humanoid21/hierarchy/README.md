# Hierarchy — 分层控制大本营（Code-as-Policy + 通用底层执行器）

> 类型：指南

本目录是 `humanoid21` **分层格斗路线（Hierarchical Combat）** 的大本营。

## 1. 核心思想（对齐 `bootstrip.md`）

将格斗控制拆解为**上层战术代码（Code as Policy）**与**下层通用动作执行器（65 维输入）**：

1. **65 维封装与指令感知**：
   通过封装后的 `CommandSimulator` 将原始 96 维观测裁剪为 **`57 维纯本体 + 8 维即时指令 = 65 维`**，并由专属 Observer 读取指令维数据以计算任务跟随损失/奖励。
2. **标准动态动作集合（路线 B — `policy_capture` 原生踱步片段）**：
   机器人站立待机的目标**不是静态死 pose**，而是由 `policy_capture`（从 `step_mbs_s42` / `balance_step_s42i`）采集的几个**双脚循环踱步动态片段**。无论是倒地起身、抗推恢复、移动停止还是出招收回，只要机器人进入并保持这几个标准动态片段中的**任意一个**即可。
3. **无套路时间窗、纯即时指令跟随**：
   底层不存在“打一套组合动作再自动收回来”的复合指令：
   - **移动**：不存在“走到某个点”，只给**方向**（前进、后退、侧移、原地转身），有方向指令就朝该方向走，给停止指令就停并回到标准动态动作。
   - **手/脚打击**：只指定哪只手/哪只脚 + 机体系下的**实时目标点 $(x^*, y^*, z^*)$**，末端越快到达该点越好；想让手/脚收回，由上层发一串撤回位置指令或直接给回到标准动作的指令。

## 2. 五步训练主线

```text
Step 1: 倒地起身 → 进入标准动态踱步动作
  │
  ▼
Step 2: 抗外力扰动 → 恢复回标准动态踱步动作（夯实平衡控制基础）
  │
  ▼
Step 3: 方向移动指令（前进 / 后退 / 侧移 / 原地转身 / 停止回标准动作）
  │
  ▼
Step 4: 双手点位极速跟随（指定左/右手 → 极速到达机体系点；撤回点位/切待机 → 收手）
  │
  ▼
Step 5: 双腿点位极速跟随（指定左/右脚 → 极速踢达机体系点；撤回点位/切待机 → 收腿）
```
