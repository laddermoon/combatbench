# EXP-CURVED-MOTION: 移动/转身技能组合实现曲线运动

> 状态：进行中
> 日期：2026-10-19
> 被测策略：`skill_train_s2b_u8000_prog/policy_exports/u09860`（P2 收敛版）

## 1. 实验目的

验证当前 6 个运动类指令（move_fwd/back/left/right、turn_l/r，全部
±1 饱和语义）能否通过**组合**实现曲线移动，从而判断移动技能集
是否完备、是否需要补训更细技能：

- 候选补训项 A：任意方向移动（vx+vy 组合）
- 候选补训项 B：边移动边转身（vx+w 组合）

## 2. 假设与判据

**H1（时间穿插）**：fwd 与 turn 段交替（粗细粒度）→ 若轨迹近似
圆弧且不失稳，则"穿插组合"可行，无需补训 B。
**H2（同时组合）**：vx 与 w 同时为 ±1/非饱和值 → 属训练从未见过的
cmd 组合/幅度。若仍能稳定弧线，则技能表达力天然完备；若明显退化
（跌倒/直线直行/原地打转），则证明需要补训。

判据指标：
- `fell`：是否提前终止（摔倒）
- `Δyaw`：episode 内总朝向变化（rad）
- `path_len` / `disp`：路径长 / 净位移
- `arc_κ`：实测平均曲率 dψ/ds vs 理想弧 κ=w/v（sim 组）
- `vx_real`/`w_real`：实测 ego 速度追踪 commanded 的程度
- 视频定性：轨迹形态（圆弧 / 折线锯齿 / 失败）

## 3. 实验设计

Env：`skill_move_env`（WarmupSteppingPlugin 起步，episode 全程
纯指令）。robot_b 零指令原地踏步作参照。T=150 步（7.5s），
seed=7，initial_distance=2.0。

**对照组**：

| ctrl_turn | [150, 0, 0, +2π] |

**A 组：穿插（fwd / turn_l 交替，均为饱和±1训练指令）**：

## 6. 结果与结论

### 6.1 量化结果（seed=7，u9860 策略，150 步≈7.5s）

| 条件 | 存活 | 净位移 m | Δyaw | 实测 ego v (m/s) | 实测 w (rad/s) |
|---|---|---|---|---|---|
| ctrl_fwd | ✓ | 2.73 | **+196°** | (1.14,−0.08) vs cmd 1.5 | +0.55 vs 0 |
| ctrl_turn | ✓ | 0.04 | +2593° | (0.09,0.01) | **+6.33 vs cmd 6.28** |
| alt_20_10 | ✓ | 3.12 | +545° | (0.43,−0.50) | +1.47 vs 2.42 |
| alt_10_10 | ✓ | 2.86 | +750° | (0.28,−0.42) | +1.99 vs 3.38 |
| alt_5_5 | ✓ | 2.35 | +778° | (0.14,−0.45) | +1.92 vs 3.14 |
| alt_3_3 | ✓ | 2.81 | +760° | (0.17,−0.59) | +2.00 vs 3.19 |
| alt_5_5r | ✓ | 0.79 | −1022° | (0.21,+0.16) | −2.56 vs −3.14 |
| sim_w100 | ✓ | 1.61 | +632° | (0.36,−0.29) vs 1.5 | **+1.48 vs 6.28** |
| sim_w050 | ✓ | 3.30 | +683° | (0.51,−0.44) | +1.81 vs 3.14 |
| sim_w025 | ✓ | 1.36 | +148° | (0.84,−0.27) | +0.39 vs 1.57 |
| sim_diag | ✓ | 3.60 | −2° | (0.45,+0.11) vs (1.5,0.75) | +0.01 |

### 6.2 发现

1. **零摔倒**：11 个条件全部完整存活，组合指令（含训练从未见过的
   同时 vx+w、vx+vy、非饱和 w）不产生失稳——技能组合的**安全性**
   完好。
2. **穿插组合（H1）成立**：fwd/turn 交替在所有粒度下产生平滑圆弧
   轨迹（非锯齿折线——惯性把转角抹圆了）。alt_5_5/alt_3_3 的轨迹
   形态接近连续弧线，dyaw 累计 ~760°。
3. **同时组合（H2）部分成立**：sim_w050/sim_w025 产生干净的长弧线
   （视频+轨迹图确认），说明 vx+w 同时指令被策略**稳定执行**——
   尽管从未训练过。但 w 响应被大幅压缩（cmd 6.28→实测 1.48），
   且非单调（w100 实测反而低于 w050）。
4. **ctrl_fwd 自身漂移**：纯前进指令 7.5s 内自发偏转 +196°——
   长时程直走的航向保持本来就不完美（eval 只测 70 步，dyaw~0.3
   被低估）。
5. **sim_diag 退化**：斜向组合退化为"慢速直行+微弱侧漂"
   （vy 0.11 vs cmd 0.75），任意方向移动不可直接组合获得。

### 6.3 结论

- **穿插穿插组合可用**：move+turn 交替足以实现可控曲线移动，
  战术层若要"绕柱走位"可直接编排，无需补训"边转边走"专项。
- **但同时组合表达力不足**：w 通道在移动中被压缩且非单调，
  无法精确控制转弯半径；vy+vx 斜向基本失效。若需要**精确
  弧线**（指定半径/速率）或**任意方向平移**，现有技能集不完备，
  值得补训组合指令（vx+w 联动、连续 vx+vy）。
- 附带发现：长时程直走的航向漂移是独立问题（与组合无关），
  若战术层需要长直线，可能需要航向保持奖励。

### 6.4 建议

1. 战术层规划**优先用穿插**（已验证可靠），预留同时组合作为
   软手段（能弯但不可控半径）。
2. 若后续战术需求涉及"边走弧边逼近对手"，补训 `vx×w` 联合
   指令采样（当前训练每 episode 只有一个通道非零，组合从未被
   探索过）——预计成本不高，机制/奖励均可复用。
3. 任意方向平移（斜走）若需要，单独补训；sim_diag 显示现有
   策略不会自发组合 vx+vy。
