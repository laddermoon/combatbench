# EXP-CURVED-MOTION: 移动/转身技能组合实现曲线运动

> 状态：进行中
> 日期：2026-10-19
> 被测策略：`skill_train_s2b_u8000_prog/policy_exports/u09860`（P2 收敛版）

## 1. 实验目的

验证当前 6 个运动类指令（move_fwd/back/left/right、turn_l/r，全部
±1 饱和语义）能否通过**组合**实现曲线移动，从而判断移动技能集
是否完备、是否需要补训更细技能：

- 候选补训项 A：任意方向移动（vx+vy 组合）
- 候选补训项 B：边移动边转身（vx+w 组合）

## 2. 假设与判据

**H1（时间穿插）**：fwd 与 turn 段交替（粗细粒度）→ 若轨迹近似
圆弧且不失稳，则"穿插组合"可行，无需补训 B。
**H2（同时组合）**：vx 与 w 同时为 ±1/非饱和值 → 属训练从未见过的
cmd 组合/幅度。若仍能稳定弧线，则技能表达力天然完备；若明显退化
（跌倒/直线直行/原地打转），则证明需要补训。

判据指标：
- `fell`：是否提前终止（摔倒）
- `Δyaw`：episode 内总朝向变化（rad）
- `path_len` / `disp`：路径长 / 净位移
- `arc_κ`：实测平均曲率 dψ/ds vs 理想弧 κ=w/v（sim 组）
- `vx_real`/`w_real`：实测 ego 速度追踪 commanded 的程度
- 视频定性：轨迹形态（圆弧 / 折线锯齿 / 失败）

## 6. 结果与结论

### 6.1 量化结果（v2，seed=7，u9860 策略，150 步≈7.5s）

| 条件 | phi<0.3 步数/150 | 持续摔倒(≥10步)次数 | phi_mean | Δyaw | 备注 |
|---|---|---|---|---|---|
| ctrl_turn | **0** | 0 | 1.00 | +2584° | 纯转身极稳 |
| alt_5_5r | 1 | 0 | 0.98 | −950° | 右转穿插意外地稳 |
| alt_5_5 | 14 | 0 | 0.85 | +728° | |
| ctrl_fwd | 18 | 0 | 0.84 | −276° | **直走也频繁踉跄** |
| sim_diag | 24 | 1 | 0.84 | +142° | |
| alt_20_10 | 49 | 1 | 0.63 | +379° | |
| alt_3_3 | 52 | 1 | 0.61 | +379° | |
| alt_10_10 | 54 | 1 | 0.58 | +710° | 1/3 时间在低位 |
| sim_w025 | 35 | 1 | 0.67 | +24° | |
| sim_w050 | 41 | 1 | 0.68 | +742° | |
| sim_w100 | **63** | 2 | 0.53 | +1266° | 最差：42% 时间失衡 |

实测 w 响应（vs cmd）：ctrl_turn 6.27/6.28（完美）；sim_w100 3.38/6.28、
sim_w050 1.93/3.14、sim_w025 0.07/1.57（大幅压缩且不稳定）。

### 6.2 发现（修正版）

1. **组合指令下频繁摔倒-起身**：phi<0.3 步数占 episode 的
   10-42%，多数条件有 1-2 次≥10步的真摔倒（S2 起身技能救回
   继续执行）。几何轨迹虽呈弧形，但**运动质量不达战术可用水位**。
2. **穿插组合并非"免费可用"**：轨迹是弯了，但 alt_10/20/3 有
   ~1/3 时间在失衡低位——靠摔倒-起身凑出来的弧线。
3. **同时组合更差**：sim_w100 高达 42% 时间失衡；且 w 响应被
   压缩、非单调（同 v1 结论）。
4. **ctrl_fwd 长时程也踉跄**（18/150 步低位）：移动技能本身
   长 horizon 稳定性有限——训练 episode 只有 70 步，150 步已超
   训练分布。
5. **ctrl_turn 极稳**（0 失衡步）：原地转身是完全在分布内的
   技能；移动+转身的**过渡瞬态**才是失衡主源。
6. **转向不对称**：alt_5_5r（右）远稳于 alt_5_5（左）——穿插
   稳定性存在左右偏置，值得注意。

### 6.3 结论（修正版）

- 初版"组合指令零摔倒、穿插即可用"的结论**不成立**。真实情况：
  曲线几何可行，但以频繁摔倒-起身为代价，**不能算技能完备**。
- **失衡主源是技能切换/组合瞬态**：纯转身稳如磐石，穿插粒度
  越细不一定越稳（alt_3_3 反而比 alt_5_5 差）——说明问题不在
  指令频率，而在 fwd↔turn 状态切换时策略本身稳不住。
- **技能集完备性判定：不完备**。需要补训的内容按优先级：
  1. **组合指令采样**（vx+w / vx+vy 联合非零）——当前每 episode
     只有单通道非零，组合分布从未被探索；
  2. **指令切换瞬态稳定性**——即使在现有离散指令下，fwd↔turn
     切换的过渡也应可学（同 episode 内 schedule 切技能即可覆盖）；
  3. 长时程移动稳定性（150 步 horizon 已超训练的 70 步分布）。

### 6.4 建议（修正版）

1. **下一训练阶段直接做"指令切换+组合"**：同一 episode 内
   schedule 切技能（训练时从未有过中途换指令），并叠加部分
   vx+w/vx+vy 同时非零的组合指令 episode——一次训练同时解决
   切换稳定性和组合表达力。
2. 战术层**暂不可用穿插编排**长距离曲线——短穿插（3-5步粒度）
   可作应急，但预期有踉跄。
3. alt_5_5r/ctrl_turn 的稳定性差异提示：补训时对称采样两侧，
   并可调查左穿插为何显著差于右穿插（可能与训练 clip/初值偏置
   或 warmup 相位有关）。

- **衔接训练显著改善了切换/组合瞬态稳定性**：phi<0.3 总占比从

  1. ~~切换瞬态稳定~~ → **基本解决**（warmup 泛化起手训练有效）

     依旧——warmup 只覆盖"任意技能→目标技能"的衔接到步，组合
     指令本身（vx+w 同时非零）的训练分布仍未探索
  3. **长时程航向漂移未解决**：ctrl_fwd +168°/150 步——warmup
     ≤35 步，不覆盖长 horizon；这与步界结算奖励（skill_step_mbs）
     要解决的问题同根
  4. alt_5_5r 逆势退化（17 低位步 + 1 摔倒）——左右不对称在
     阶段二被放大而非消除，待查
