# 底层执行器（Low-Level Executor）五步深化训练方案

> 类型：记录 ｜ 状态：规划定稿（对齐 `bootstrip.md` + 路线 B） ｜ 日期：2026-10-16

本文档基于 `bootstrip.md` 的设计思想，定义 `humanoid21` 分层控制底层模型的 **66 维输入契约（9 维 v2 指令）、路线 B 标准动态动作片段机制、即时指令编码与五步训练流水线**。

> ⚠️ **契约更新（2026-10-16）**：指令空间已定稿为 9 维 v2（`(vx,vy,w,h)` + `(eff_type,eff_side,txyz)`），总观测 66 维——**见 `COMMAND_DESIGN.md`**（含"指令空间 vs 支持子集"讨论）。本文 §1.2 的 8 维字段表、§3 Step4/5 中的 `act_mode`/`phase` 编码已过时，字段语义以 COMMAND_DESIGN.md 为准；各阶段的训练目标与奖励思路仍然有效。

## 0. 核心设计范式（与旧方案的本质区别）

1. **标准状态是“动态踱步片段集合”，而非“静态立正 Pose”**：
   机器人站立、抗扰恢复、停步、收招后的默认归宿，是一组（$3 \sim 5$ 个）**双脚循环交替踱步的动态片段**（通过路线 B `policy_capture` 从已有步态策略中采集）。训练时采用**多片段集合最小距离 / 最大相似度匹配**——只要机器人的实时运动状态落入任意一个片段的任意相位即视为达标，从而彻底告别静态“死木桩”站姿，时刻保持高机动响应性。
2. **移动只给“方向”，不给“终点坐标”**：
   移动指令仅表达机体系下的运动方向（前进、后退、左右侧移、原地转身）。有方向指令就持续朝该方向走；要停下就由上层发停止指令（回到标准动态动作）。
3. **手/脚打击是“无套路的极速位置伺服”，出击与收回同构**：
   底层不存在“一套完整出拳+自动收手”的复合指令。指令只告诉底层：**“现在让哪只手/脚去机体系下的 $(x^*, y^*, z^*)$”**，底层唯一的任务是在保持不倒的前提下**越快到达该点越好**。
   - **出拳/踢腿**：上层把目标点 $(x^*, y^*, z^*)$ 设在身前打击区；
   - **收手/收腿**：打完后，上层给一串撤回胸前/地面的位置指令，或直接切回标准动态动作指令。

## 2. 路线 B：标准动态动作片段集合（Standard Dynamic Clips）

### 2.1 片段来源与构建（`policy_capture`，已执行 2026-10-16）
利用已有的 `mocap/humanoid21/policy_capture/` 工具链，从已收敛的 `step_mbs_s42`（收敛版导出 `baseline/runs/step_mbs_s42/policy/`，经 `GaitClockAdapterPolicy` 包装）在无推力环境（`capture/stepping_capture_env.yaml`）中采集 $12$ 集 $\times 400$ 步全 episode 轨迹（无摔倒，`/data1/dev/policy_capture/step_mbs_stepping/`）。

由 `extract_standard_clips.py` 筛出 **$M = 5$ 段** 高质量双脚循环交替踱步片段（$L = 40$ 步 $= 2\text{ s}$，覆盖约 2 个完整左右交替周期）：
- 质量门：全程直立（`gravity_proj_z < -0.80`、`root_z > 1.05`）、原地（窗口内水平位移 $< 0.4\text{ m}$）、承重脚交替次数 $\ge 2$；
- 实测：单脚离地高度峰值 $15 \sim 22\text{ cm}$，承重脚交替 $6 \sim 8$ 次/窗口，root z $\approx 1.28\text{ m}$ 平稳；
- 上肢保持原生轨迹（`step_mbs` 自然收臂姿态），存盘为 `baseline/humanoid21/hierarchy/assets/standard_stepping_clips.npz`（含 53 维特征、原始关节/根姿态、逐 clip 溯源 meta）。

### 2.2 多片段取 `max` 的动态匹配奖励（`StandardClipObserver`）
为了保证机器人学到的是**动态循环踱步**而不是停在某一帧的静态 Pose，匹配特征不能只看单帧，必须使用 **短时状态转移对（Short-Window Transition）** $\mathbf{z}_t = [f_{t-\Delta},\ f_t]$（其中跨度 $\Delta = 4$ 步 $= 200\text{ ms}$）：
- 单帧特征 $f_t$ 包含：归一化关节角（21）+ 归一化关节角速度（21）+ 重力投影（3）+ 双脚相对骨盆坐标（6）+ 双脚触地标志（2）。
- 设标准片段库共有 $M$ 个片段 $\{\mathcal{C}_1, \dots, \mathcal{C}_M\}$，当前状态转移 $\mathbf{z}_t$ 对整个集合的匹配得分为**与最近片段帧的相似度（取 `max`）**：
  $$r_{\text{std}}(t) = \max_{m \in \{1..M\}}\ \max_{\tau \in \mathcal{C}_m} \exp\Big(-\alpha \cdot \|\mathbf{z}_t - \mathbf{z}_{m, \tau}\|_W^2\Big) \in (0, 1]$$
- **物理效果**：
  1. 只要机器人处于这几个标准踱步片段中的**任意一个片段、任意一个步态相位**，且在接下来的 $200\text{ ms}$ 内顺着该片段的趋势继续踱步，就能持续拿到接近 `1.0` 的满分；
  2. 如果机器人双脚钉死不动（变成静态木桩），虽然 $f_t$ 可能像某一帧，但 $200\text{ ms}$ 后的 $f_t$ 没有发生片段要求的重心与脚部交替转移，$\|\mathbf{z}_t - \mathbf{z}_{m,\tau}\|^2$ 会立刻变大，得分骤降。

## 3. 五步递进训练流水线

所有阶段均遵循**不倒优先（Balance-First）**：`r_potential`（`aw = 3.0`）与 `r_fall`（`aw = 2.0`）全程在线，其余任务通道均乘以安全门控 $g_{\text{safe}}(\varphi_t) = \mathbb{I}(\varphi_t \ge 0.75)\cdot \varphi_t^2$。

---

### Step 1：倒地起身 $\rightarrow$ 进入标准动态动作（`exp_hier_s1_standup`）

- **目标**：机器人从任意倒地姿态快速站起，站起后**不停留在静态死姿，而是直接切入双脚循环踱步的标准动态动作**。
- **输入指令**：全程恒为 `STAND = (0, 0, 0, 0, 0, 0, 0, 0)`。
- **Warm-start**：从 `standup_mbs_ef05_s42` (`u350`) 切出 65 维初始权重 `hier_s0_init.pt`。
- **奖励通道（3 通道）**：
  1. `r_potential`（`aw = 3.0`）：四阶段起身势能 $0.01 \cdot \varphi(t)$（负责从倒地站起来）；
  2. `r_fall`（`aw = 2.0`）：防复摔惩罚；
  3. `r_std_clip`（`aw = 2.0 * g_safe(φ)`）：标准动态踱步片段集合匹配奖励 $r_{\text{std}}(t)$（仅在站立后 $\varphi \ge 0.75$ 激活，引导机器人进入动态踱步循环）。
- **验收标准**：
  - `standup_success >= 0.99`（倒地必起）；
  - 站起后 `std_clip_score >= 0.65` 且 `step_cycles >= 8/ep`（确认双脚在持续循环踱步，而非静态木桩）。

---

### Step 2：抗外力扰动 $\rightarrow$ 恢复回标准动态动作（`exp_hier_s2_balance`）

- **目标**：在标准动态踱步状态下承受 12 级随机推力（$40\text{ N} \rightarrow 100\text{ N}$，时长 $1 \rightarrow 40$ 步），被推时不摔倒，**推力结束后自动恢复到标准动态踱步动作**。
- **输入指令**：全程 `STAND = (0, 0, 0, 0, 0, 0, 0, 0)`。
- **Warm-start**：承接 Step 1 最优 checkpoint。
- **奖励通道（3 通道）**：
  1. `r_potential`（`aw = 3.0`）；
  2. `r_fall`（`aw = 2.0`）：含 `fall_onset` 惩罚 + `wall_lean` 惩罚 + `push_clean_bonus`；
  3. `r_std_clip`（`aw = 2.0 * g_safe(φ) * not_pushing`）：在非受推窗口（或轻推窗口）持续吸引机器人回到标准动态踱步状态；受强推瞬间允许破开架势迈大步卸力。
- **验收标准**：
  - 12 级推力课程打满（100N），`recovery >= 0.92`；
  - 推力观察窗结束后 1 秒内，`std_clip_score` 迅速恢复至 $\ge 0.60$。

---

### Step 3：移动指令训练（`exp_hier_s3_move_mbs`）—— v2 契约版

- **目标**：跟随 `(vx*, vy*, w*)` 身体指令——全方向平移、原地转身、弧线行走、急停回标准步态。速度上限 `V_MAX=1.5 m/s`，转速上限 `W_MAX=2π rad/s`。
- **指令下发**：`episode_options["move_schedule"]` 携带分段表 `[[n_steps, vx, vy, w], ...]`，`CommandSimulator` 编译为逐步指令；段首为 STOP 引导段（60~100 步，先起身）。指令存于 obs 尾部，天然与动作逐步对齐。
- **奖励离线段级计算（关键设计）**：`MoveTrackObserver` 只记录 `root_x/root_y/yaw/h_root`，**不做每步评分**——每步瞬时速度全是噪声。实验在 `_build_agent_trajectory` 离线重建每个指令段，对 `[a+settle, b)` 窗口计算段级速度 `v̂`（逐步位移投到该步朝向系再平均）与段级转速 `ŵ`，与指令比对：
  $$s_{\text{move}} = e^{-\|\hat v - v^*\|^2/\sigma_v^2},\qquad s_{\text{turn}} = e^{-(\hat\omega - w^*)^2/\sigma_\omega^2}$$
  段得分广播到全段（含过渡窗口）。弧线指令（v、w 同时非零）天然正确评估。
- **奖励通道（4 通道）**：`r_potential`(aw=1) / `r_move`(aw=3φ²) / `r_turn`(aw=3φ²) / `r_std_clip`(aw=3φ²·I[STOP段])。STOP 段即 `(v*,w*)=0` 的段，复用同一公式（目标为零速）。
- **课程 = 只调意图采样空间，奖励公式全程不变**：
  | 级 | 采样空间 |
  |---|---|
  | L0 | v∈[0.2,0.5] 全方向连续，w=0，段 60-80 步，STOP 35% |
  | L1 | v∈[0.2,0.9] |
  | L2 | v∈[0.2,1.5] 全速度 |
  | L3 | + 原地转 w∈±[0.5,1.5]（25%）+ 弧线（20%） |
  | L4 | 段 30-60 步，w≤2π，更密急停/反向 |
  晋级：eval 段级 `v_err` 中位 < 0.12 m/s（含转向后加 `w_err` < 0.3）、success ≥ 0.95，连续 2 次。
