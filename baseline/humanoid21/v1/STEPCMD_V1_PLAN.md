# 步令实验 V1 训练方案（STEPCMD V1）

> 残差编码步令的首次训练验证：Base S2、无扰动、只学步令——
> 保持平衡的同时 ASAP 收敛目标。指令语义见 STEP_CMD.md（D20）；
> 本文档只写本实验的训练方案。

## 1 目标与对照

- **主要问题**：残差编码 + 软指令通道，策略能否在保平衡
  的前提下学会"尽快到达落点并保持"
- **Base**：S2 u1680（无推力插件），指令流从帧 0 起
  **全程开启、无站立门控**——"失衡时忽略指令"是策略要
  学的行为，不是系统给的豁免
- **对照语义**：与 S4-NoArm（类别编码）同 S2 基底、同
  无扰动——隔离变量 = 编码形式

## 2 任务语义

- 指令 = 哪只脚 + 到哪（残差向量）；ASAP 固有语义，
  无相位、无时间字段
- 全零 = 保持原地不动（合法指令，计分见 §4）
- 订单 0.5s = 10 帧：到期结算、轮换下一令；
  预算对策略不可见

## 3 指令源（`step_cmd_gen.py`，已定稿）

| 参数 | 值 |
|---|---|
| 动脚 | 交替 0.8 / 同脚 0.1 / 保持 0.1 |
| 方向 | 前 0.8 / 后 0.2 |
| 纵向偏移 | 前 U(0,0.53) / 后 U(0,0.40) m（0=并脚） |
| 横向脚距 | U(0.42,0.63) m |
| 转向 | 上令无转→新转 0.15；有转→续0.55/反0.05/停0.40；±U(5°,30°) |
| 约束 | 双脚欧氏距 ≤0.62m；撞墙拒采 ≤8 次兜底保持 |

目标在发令时刻锚定世界系（`cmd_target`），此后不变；
obs 每帧写真值重算的残差。

## 4 观测

79 维布局不变。`step_cur = [foot, Δx, Δy, Δψ, 0, 0]`
（Δx/Δy = 动脚踝→目标，前向=躯干 yaw 投影；Δψ = 朝向
残差）；`step_next` = 假想后态系中的下一条残差（静态
预览）。arm 段全零（V1 无臂令）。

## 5 奖励（5 通道）

| 通道 | 逐帧定义 | aw 初值 |
|---|---|---|
| r_potential | 0.01×φ（沿用 S2） | 3.0 |
| r_fall | 摔倒/靠墙（沿用 S2） | 2.0 |
| r_step_mv | −‖Δx,Δy‖_t | 1.0 |
| r_step_st | −max(0, ‖drift‖ − 0.03)_t | 0.5 |
| r_step_yaw | −max(0, \|Δψ\| − 0.05)_t | 0.5 |

- **r_std_clip 移除**——其 cadence/pose 项奖励 s42i 站姿
  节律，与迈步直接冲突
- **积分语义**：mv/st/yaw 逐帧瞬时量，令窗口内自然积分
  = 误差曲线下面积——**ASAP 由此而来**（每晚一帧到位
  = +error·dt，无单独速度通道）
- **归一化**：mv/yaw 令级统计取窗口均值（对令长归一，
  抗截断/变预算）；st 不归一化（漂移死区原始累计）
- **HOLD 令计分**：无动脚 → mv=0；双脚皆 stance 计漂移；
  yaw 残差按发令时刻朝向计——"原地不动"是被测的真指令
- stance 脚只量 xy 漂移不量朝向（转向令中原地拧转合法；
  死区 3cm 覆盖落点微修）

## 6 结算与 eval 指标

每 10 帧到期记录：**d_mv / d_st / d_yaw**（终态残差）、
**t_arrive**（首次入阈时间，阈 0.10m/0.10rad）、hold 占比、
falls、recovery 不适用（无推）。
**滑步 watch**：动脚"在令期"贴地帧占比（摆动期力≈0 但踝部
仍位移 = 滑行证据）。

## 7 训练配置

- warm-start：S2 `checkpoint_u01680.pt`，`--reset-update`
- 无推力插件；PPO 超参沿用 S2（lr 3e-5 / kl 0.03 / 512ep×400f）
- 400 帧 episode ≈ 40 令/ep
- cmd 段语义：S2 全零 → 残差新激活（权重重适应，非错误）

## 8 已知风险

- **滑步**：残差可被贴地滑动收敛且积分奖励其"快"——
  V1 只 watch 不阻断；学了再议离地间隙项
- **失衡跟令**：无门控 → 失衡帧残差大但属可学信号；
  摔倒由 r_fall 终止兜底
- **结算在失衡帧照跑**：无门控的直接推论，令不受身体
  状态影响——与部署语义一致
