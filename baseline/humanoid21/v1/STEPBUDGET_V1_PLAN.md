# STEPBUDGET V1 — 方向 + 时间预算步令实验方案

> 状态：**草案，待用户审阅**（标 ⏳ 的为未决项）
> 实验名：`v2_stepbudget`，首轮 `v2_stepbudget_r1`

## 0. 一句话

步令从"去某个点"改为"**往某个方向迈一步，迈多远由时间预算
决定，步幅受站姿包络封顶**"；朝向由独立的绝对目标控制。
指令流由 **Clip 随机组合（80%）+ 逐步纯随机（20%）** 生成。
从平衡策略起训（指令输入语义全变，不热启步令策略）。

## 1. 动机（Attack Harness v1 暴露的问题）

- **步令动态性与衔接弱**：STEPACE 连续大步 d_mv≈0.3；sprint
  扫描最快仅 0.37 m/s；攻击逼近在 d≈0.5 停滞，绕行/弧线走位
  基座做不到。
- **根因 = 指令分布**：现采样器逐令 i.i.d.、无时序结构，"连续
  走"在训练里罕见；时长不可见，策略学成"走一步→到位→停"。
- **点目标语义与"快"冲突**：固定落点下"快"只等于"早到早停"；
  "长 Δ + 短预算"使残差惩罚与终帧落地互相打架。
- **锚定误差累积**：`cmd_target` 以轴心脚锚落点，开环误差逐步
  累积（STEPACE 开环左漂 -1.4m）。

新语义下：步长 = 执行结果（预算 × 脚速，包络封顶），规划层
只需给"方向 + 节奏"——与攻击规划实际需求一致；闭环纠偏由
规划层逐步重给方向承担。

## 2. 步令编码（cur / nxt 各 6 维，obs[67:73] / obs[73:79]）

| 维 | 语义 |
|---|---|
| 0 | 动脚：−1 / +1；0 = 保持（双脚不动） |
| 1-2 | **迈步方向**单位向量（机体系，前向=躯干 yaw 水平投影）；`(0,0)` = 原地踏步 |
| 3 | Δψ：当前 yaw → **绝对目标 yaw** 的残差（每帧真值重算）⏳ 见 §4 |
| 4 | 时间预算 /20：cur = 剩余帧，nxt = 总预算 |
| 5 | 预留（0） |

- **方向锚定**：发令时刻锚到世界系，每帧按当前躯干 yaw 换算为
  机体系写 obs（身体转动不使脚走弧线）。nxt 方向以当前机体系
  表达。
- **预算 = 唯一时钟**：剩余帧归零即晋升（cur ← nxt），脚落地不
  提前晋升；脚提前到包络 → 落地等待。
- **预览即承诺**：cur ← nxt 原样晋升，Clip 内外、Clip 切换时
  一律不变（违反此契约已实测会使执行崩溃，见 STEPACE 修复记录）。
- 臂令段 obs[57:67] 本版置零（见 §8）。

## 3. 步幅包络（D12/D14 10 态站姿）

以**当前轴心脚位置**为原点、**目标终定朝向**为参照系：

- 外界 = L2W/R2W 终态：纵向 |stagger| ≤ **0.528 m**（2 档 ×
  0.264），横向脚距 ≤ **0.625 m**（WIDTH_W）
- 内界：横向脚距 ≥ **0.25 m**（防交叉腿）⏳ 数值待确认
- 包络内的位移才计推进奖励；越界部分不计且计过冲罚
- 动脚最大单步位移隐含 ≈1.06m（R2→L2），实际由预算自然限制

## 5. 指令源：Clip 随机组合 + 20% 随机

### 5.1 结构

episode 指令流 = Clip 序列；每个 Clip 结束后按权重抽下一个。
每步以 P=0.2 替换为纯随机步令（方向均匀、预算 U(3,20)、脚
随机，可同脚连迈）。所有步方向加 N(0,15°) 噪声、预算 ±2 帧
抖动（clip 到 [3,20]）。

### 5.2 Clip 库（草案，⏳ 清单与权重待确认）

| Clip | 步数 | 方向 | 预算(帧) | 朝向 | 权重 |
|---|---|---|---|---|---|
| 直行/斜行 | 4–10 | 前 ±30° | 8–14 | 跟随方向 | 0.15 |
| 快走 | 4–10 | 前 ±20° | 3–7 | 跟随方向 | 0.10 |
| 弧线行走 | 4–10 | 逐步旋转 | 8–14 | 跟随方向 | 0.10 |
| 侧移（左/右） | 3–6 | ±90° ±20° | 5–10 | 锁定 | 0.10 |
| 斜后撤 | 2–5 | 后 ±45° | 8–14 | 锁定 | 0.08 |
| 绕点侧移 | 4–8 | 切向 | 8–14 | 持续转向圆心 | 0.08 |
| 原地转身 | 2–5 | (0,0) | 5–10 | 大转角目标 | 0.08 |
| 碎步调整 | 2–6 | 随机 | 3–5 | 微调 | 0.10 |
| 前弓 + 回收（左领/右领） | 2 | 斜前 → 反向 | 14–20 | 锁定 | 0.07 |
| 侧弓 + 回收（左/右） | 2 | ±90° → 反向 | 14–20 | 锁定 | 0.07 |
| 保持 | 1–3 | — | 5–15 | 不变 | 0.07 |

### 5.3 动脚选择

- Clip 内交替为主；侧移/侧弓时**运动侧的脚先迈**
- 落点预测越出包络（交叉/超宽）→ 换脚或缩成原地踏步
- 撞墙预测 → 拒采重抽（沿用 collide_fn，≤8 次兜底保持）

## 6. 奖励（逐帧）

| 通道 | 定义 | aw 初值 |
|---|---|---|
| r_progress | 动脚速度在指令方向上的投影；越出包络部分不计，过冲计罚 | 1.0 |
| r_lateral | 动脚垂直于指令方向的偏离 −‖d⊥‖ | 0.5 |
| r_land | 预算末帧动脚着地 +1（只奖着地，不奖"恰在末帧"） | 0.5 |
| r_yaw | −max(0,\|Δψ\|−0.05) × w(t)，w 随预算消耗 0→1 | 0.5 |
| r_pivot | 轴心脚 xy 漂移死区：发令时轴心脚悬空或令龄 <5 帧 → 10cm，否则 4cm | 0.5 |
| r_potential | 0.01×φ（沿用 S2，h_cap=1.10） | 3.0 |
| r_fall | 摔倒/靠墙（沿用 S2） | 2.0 |

- 保持令：r_progress/r_lateral/r_land 不计；双脚皆按 r_pivot
  计漂移；朝向照常
- 原地踏步（方向 0）：r_progress 不计；r_land 照计；动脚按
  4cm 死区计原位偏离
- 权重为初值，smoke 后调

## 7. 评估指标

| 指标 | 用途 |
|---|---|
| 预算 → 步长曲线（前/侧/后分桶，均值+方差） | 规划层标定表 |
| 各方向最快步速 & 对应最优预算 | 回答"什么预算跑得最快" |
| 方向误差（实际位移方向 vs 指令） | 方向遵从 |
| 末帧着地率 | 节奏遵从 |
| 包络违规率（外界/内界） | 站姿安全 |
| 轴心脚漂移 | 滑步监测 |
| 朝向终点误差 | 朝向遵从 |
| 摔倒率、min φ | 平衡底线 |
| 按 Clip 类型分桶完成度 | 场景覆盖 |
