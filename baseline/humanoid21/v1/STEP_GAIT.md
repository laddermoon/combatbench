# 步态姿态集与步令编码（Step Gait）

> S4 步指令遵从训练的有限姿态状态机 + 步令编码定义。
> **步令 = 声明式终态指令**：描述"哪只脚动 + 完成后的朝向 +
> 完成后的双脚姿态"，不描述动作轨迹。评分在步边界对比实际
> 姿态/朝向与目标。
>
> 关联决策：D7（原始 6 维编码，**已被本版取代**）、D8（22 维
> 指令段布局）、D12（S4 总体）、D13（本版编码定稿）。
>
> **注意**：下文"步令编码（6 维，定稿）"一节已被 **D20 残差
> 向量编码**取代（见 STEP_CMD.md）；本文档的姿态集/调度语义
> 部分仍有效（姿态集降级为训练侧目标采样器）。

## 姿态空间：5 交错档 × 2 宽距 = 10 态

**轴 1 · 交错档**（前后错位，单位=小步长档）：

| 档 | 名称 | 含义 |
|---|---|---|
| L2 | 左弓 | 左脚在前 2 档（深交错，弓步感） |
| L1 | 左领 | 左脚在前 1 档（半步，≈拳击正架 orthodox） |
| E  | 平步 | 双脚齐平（基准） |
| R1 | 右领 | 右脚在前 1 档（≈反架 southpaw） |
| R2 | 右弓 | 右脚在前 2 档 |

**轴 2 · 宽距**（横向脚宽）：N=常距 / W=宽距。

**命名**：交错名 + 宽距后缀（N 无后缀，W 加"宽"）：
平步、左领、右领、左弓、右弓／马步、左领宽、右领宽、左弓宽、右弓宽
（E-W 特称马步）。系统码 `En, L1n, L2n, R1n, R2n, Ew, L1w, L2w, R1w, R2w`。

## 步令编码（6 维，定稿）

| 维 | 取值 | 语义 |
|---|---|---|
| 0 脚动 | −1 / +1 | −1 左脚动 / +1 右脚动；**0 不合法** |
| 1 转向 | −1 / 0 / +1 | 完成后 torso 朝向 左转 / 不转 / 右转（±30° 暂定） |
| 2 前脚 | −1 / 0 / +1 | 终态左脚在前 / 齐平 / 右脚在前 |
| 3 纵档 | −1 / 0 / +1 | 纵向交错 小 / 不迈 / 大（**维2=0 时本维必为 0**） |
| 4 横向 | −1 / +1 | 终态宽距 常距 N / 宽距 W |
| 5 预留 | — | 0 |

**语义**：

- 每条步令 = 指定脚动一次（抬起→落地），完成后双脚应处于
  (维2×维3×维4) 编码的终态姿态，朝向较下发时偏转 维1 量。
- **脚动维无 0**——每条步令必有一脚迈动，步边界永远是
  该脚落地事件，无"不定脚/纯碎步"指令。
- `原`（全零向量）不是合法步令，是 **无指令哨兵**：调度器
  不排程时填零 = 原地小碎步保平衡（沿用 D8 全零语义）。
- **自环 = 踏步**：目标姿态 = 当前姿态时，步令 = 该脚抬落
  原位（marking time），如 `左→左领` @ 左领。
- **脚维 ≠ 等价**：同一终态经左脚/右脚达成的**位移方向相反**：
  `右→右领` = 右脚前迈（前进），`左→右领` = 左脚后撤（后退）。
  脚选择隐式编码移动方向——采样层利用此性质控制行走方向。
- **转向独立**：转朝向与哪只脚动无关（旧"脚×转向合法性"
  之争作废，降级为纯物理问题交训练）。

## 步令读法

`脚 → 终态姿态 [·转]`：

| 向量 | 步令名 | 语义 |
|---|---|---|
| `[+1,0,−1,−1,−1,0]` | `右→左领` | 右脚动 → 终态左领（右脚后撤半步，等价后退） |
| `[−1,0,+1,+1,−1,0]` | `左→右弓` | 左脚动 → 终态右弓（左脚后撤大步） |
| `[−1,+1,0,0,+1,0]` | `左→马步·右` | 左脚动+右转 → 终态马步 |
| `[+1,0,−1,−1,−1,0]` @ 左领 | `右→左领` | 右脚落回原槽 = 右脚踏步 |
| `[0×6]` | `原` | 无指令哨兵（碎步保平衡，非合法步令） |

## 姿态 → 步令生成表

**任何终态都合法可编**——可达性不在表内管，难度（动脚位移 =
|Δ交错档|）交给采样权重。

| 终态 | 等价步令（·转可叠加 ±1） |
|---|---|
| 平步 | `左→平步` `右→平步` |
| 左领 | `左→左领` `右→左领` |
| 左弓 | `左→左弓` `右→左弓` |
| 右领 | `左→右领` `右→右领` |
| 右弓 | `左→右弓` `右→右弓` |
| 马步 | `左→马步` `右→马步` |
| 左领宽 | `左→左领宽` `右→左领宽` |
| 左弓宽 | `左→左弓宽` `右→左弓宽` |
| 右领宽 | `左→右领宽` `右→右领宽` |
| 右弓宽 | `左→右弓宽` `右→右弓宽` |

**位移代价**（采样权重输入）：动脚矢状位移 = |stagger_当前 −
stagger_目标|（档）；宽距切换 = 固定一次横向位移。例：
平步→左领 动脚移 1 档；右弓→左弓 动脚须飞 4 档（合法但近不可能，
采样近零权）。

## 边界与评分语义

- **步边界事件** = 动脚触地确认（迟滞状态机：SWING→PLANTED
  需脚力>0.4×体重连续≥3 action步；PLANTED→SWING 反向<0.1）；
  超时兜底（60 步未落地强制轮转，按现状评分）。
- **评分**：落地稳定后（PLANTED 确认+2~3 帧延迟）对比实际
  姿态 vs 目标姿态；朝向 = 下一边界实测 yaw 偏差 vs 指令偏转。
- **轮转**：边界处 `step_next→step_cur`，采样器生成新 next。
- **无指令期**：step_cur 全零 = 自由碎步（原），无评分；
  可预置 step_next 让策略预见。
- **指令流**：与臂脚本同机制——episode 起即轮转、摔倒不停；
  无奖励门控，策略自行取舍平衡/遵令。

## 步令调度器（`step_scheduler.py`）

Markov 采样器：上下文 = (指令姿态, 上轮动脚, 上轮转向)，
因子化条件采样代替显式转移矩阵（`SchedulerParams` 全旋钮）：

1. **脚**：P(交替)=0.9——步态最强先验，同脚 0.1 覆盖跳步；
2. **转向**（持续性）：直行中 P(发起)=0.15；转向中
   P(续)=0.55 / P(停)=0.40 / P(反)=0.05 → 转向以 ~2.5 步片段出现
   （稳态转向占比 ≈0.27）；
3. **目标姿态** 双轴因子化：Δstagger 档权
   {0:.30, 1:.44, 2:.16, 3:.06, 4:.04} × 方向偏置
   e=sign(Δs)·foot（前进×1.4 / 后撤×0.8 / 横原×1.0）；
   宽距翻转独立 Bernoulli(0.12)；
4. **碰撞约束层**：`collision_fn(order,state)->bool` 由仿真侧
   注入（撞墙/撞对手预测），拒绝重采 ≤3 次，失败退化为
   **踏**（交替脚→当前姿态·不转）；
5. 链状态用**指令态**（不问执行结果），矩阵可经
   `transition_matrix()` 物化 20×20 供遍历性/稳态验证。

自测：`python3 step_scheduler.py`（边际统计对表 + 矩阵
行和 + 稳态分布）；`simulate()` 可造任意长度测试序列。
