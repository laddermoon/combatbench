# 步态姿态集（Step Gait Postures）

> S4 步指令遵从训练的有限姿态状态机定义。
> 每条**步令**（step order）= "到某个目标姿态的单步转移指令"，
> 即"迈步完成后的双脚姿态配置"，不是动作轨迹；
> 评分在步边界对比实际姿态与目标姿态。
>
> 关联决策：D7（6 维步令编码）、D8（22 维指令段布局）、本文 = D12 附件。

## 姿态空间：5 交错档 × 2 宽距 = 10 态

**轴 1 · 交错档**（前后错位，单位=小步长档，对体心对称）：

| 档 | 名称 | 含义 |
|---|---|---|
| L2 | 左弓 | 左脚在前 2 档（深交错，弓步感） |
| L1 | 左领 | 左脚在前 1 档（半步，≈拳击正架 orthodox） |
| E  | 平步 | 双脚齐平（基准） |
| R1 | 右领 | 右脚在前 1 档（≈反架 southpaw） |
| R2 | 右弓 | 右脚在前 2 档 |

**轴 2 · 宽距**（横向脚宽）：

| 档 | 名称 | 含义 |
|---|---|---|
| N | 常距 | 正常步宽（值待实测 s42i 定） |
| W | 宽距 | 宽跨步宽 |

**命名规则**：交错名 + 宽距后缀（N 无后缀，W 加"宽"）。
10 态全名：平步、左领、右领、左弓、右弓（常距系）／
马步、左领宽、右领宽、左弓宽、右弓宽（宽距系；E-W 特称马步）。

系统码 = `{交错码}{宽码}`：`En, L1n, L2n, R1n, R2n, Ew, L1w, L2w, R1w, R2w`。

## 步令读法（6 维指令的可读名）

一条**步令** = 6 维向量（D7 编码）的可读串：`脚+矢状+横向+幅·转`

| 维 | 取值 | 念法 |
|---|---|---|
| 0 脚 | −1 / 0 / +1 | 左 / 原 / 右 |
| 1 矢状 | −1 / 0 / +1 | 后 / — / 前 |
| 2 横向 | −1 / 0 / +1 | 内 / — / 外 |
| 3 步幅 | −1 / +1 | 小 / 大（**固定离散两档**，无中间档） |
| 4 转向 | −1 / 0 / +1 | ·左 / — / ·右 |
| 5 预留 | — | — |

示例：`[+1,+1,0,−1,0,0]`=`右前小`；`[−1,+1,+1,+1,+1,0]`=`左前外大·右`；
`[0,0,0,0,+1,0]`=`原·右`（pivot）；`[0×6]`=`原`（小碎步保平衡）。

**脚=0（原地）分宽距**：原地是自环、保持当前姿态——
名称继承姿态宽距：`原`（常距碎步）/ `原宽`（宽距碎步）、
`原·右`（常距 pivot）/ `原宽·右`（宽距 pivot）。
脚=0 时 dim2 闲置，**复用为目标宽距指示**：`−1`→要求收常距、
`+1`→要求保宽距、`0`→维持现状（语义标注，实际收距靠下一
脚令完成）。

姿态名管状态（左领/平步…）、步令名管转移（右前小/左后大…）——
配套使用："平步→左领 = 步令 `左前小`（或等价 `右后小`）"。

## 转移图（草案，未定）

> ⚠ 本节是**程序化枚举的可达性草案**，不是结论——
> 哪些转移实际进入 Markov 链、权重多少、非法规则裁剪，
> 均待定稿。下表仅表示"几何上一步可达"。

单步 = 恰好一脚移动（矢状 ±1/±2 档，可选横向 ±1 切换宽距）。
每格 = 该转移的**全部等价步令集**——同一姿态转移可由两脚
分别完成（如 `L:前小` 与 `R:后小` 产出相同几何），选脚即
采样的自由度。`—` = 一步不可达（|Δ交错|>2）。

步令记号沿用读法格式：`脚:矢状[幅度][横向]`（`L:后小外` =
`左后小外`）。`原地` = 脚=0 自环。

## 转向修饰符

转向不属姿态集（朝向是连续上下文），作为指令修饰叠加在
任意转移上：`目标yaw = 边界时刻yaw + 指令Δyaw`。

**脚×转向约束（待确认）**：几何推导为 *异侧脚前进转*
合法（R:前+左转 = 左转标准机制，外圈脚迈弧线；同侧脚前进+
同向转 = 交叉步非法）。用户表述"右脚前进不能向左转向"与此
相反，可能锚定"前进"于新朝向语义——**实现前需拍板**，转移
矩阵上只是一行约束差别。

## 边界与评分语义

- **步边界事件** = 指令脚触地确认（迟滞状态机：SWING→PLANTED
  需脚力>0.4×体重连续≥3 action步；PLANTED→SWING 反向<0.1）；
  超时兜底（60 步未落地强制轮转按现状评分）。
- **评分**：落地稳定后（PLANTED 确认+2~3 帧延迟）对比
  实际姿态 vs 目标姿态；朝向在下一边界实测偏差。
- **脚=0 指令**：无落地脚，固定 40 步窗口到期轮转，评朝向。
- **指令流**：与臂脚本同机制——episode 起即轮转、摔倒不停；
  无奖励门控，策略自行取舍平衡/遵令。
