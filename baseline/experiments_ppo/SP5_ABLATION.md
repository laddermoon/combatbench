# P5 轨迹 PPO 奖励消融对比（stand_punch 任务）

> 目的：P5 稀疏轨迹（5点×时间）作为 PPO 奖励的最佳利用方式。
> 协议：同 checkpoint(s42i_b u1680)、同 seed、同 13×50ms 步、同紧盒采样；
> 唯一变量 = 奖励构造方式。基建 `p5_tracking_base.py`，变体 `exp_sp5_*.py`。

## 已确认的结论

1. **逐帧点距的朴素形式就够**：v0（纯欧氏距离、均匀权重、硬时间锁）
   能越过历史上所有"精心调参"版本的平台期——此前 v1/v2 的复杂
   通道结构没有买到收敛高度。

2. **权重是当前唯一强杠杆**：strike 段给打击手 3-6× 权重的两个变体
   全程领跑。含义：瓶颈在拳臂精细跟踪，均匀权重把它稀释了。

3. **距离核形状不重要**：gauss（无尾）/tail（宽尾）双双卡死——
   掉队后有没有恢复梯度不是主因，主因是拳臂没学到位。
   （gauss 失败符合预期；tail 失败说明宽尾也救不了弱拳。）

4. **时间锚定不能松**：sparse（只考关键帧）和 prog（自定进度）
   都卡死——硬时间锁的"节拍压力"是必要的，松掉它策略学不会推进。

5. **yaw/geom 通道是净正贡献但非主因**：都在第二梯队前列，
   yaw 对姿态质量的作用待视频验证。

## 待终局确认

- phase vs hand3 的最终收敛高度（目前 phase 小幅领先）
- 终态姿态质量（torso pitch 代理 + 视频目检）
- v0 是否最终追平——若追平，说明该任务的最佳奖励就是最简单的

## 变体定义（单变量消融）

- `sp5_v0`：r=-d(欧氏), 5通道, aw=1, 硬时间锁 ← **极简基线**
- `sp5_gauss`：v0 但 exp(-d²/σ²)
- `sp5_tail`：v0 但 峰+宽尾核
- `sp5_axial`：v0 但误差按攻击轴分解(横向×2)
- `sp5_sparse`：v0 但只在4个关键帧落点打分
- `sp5_prog`：v0 但参考帧按已达成进度索引
- `sp5_hand3`：v0 但打击手 aw=3
- `sp5_phase`：v0 但相位权重(load:脚3头1,strike:打击手6)
- `sp5_yaw`：v0 + r_torso_yaw 通道
- `sp5_geom`：v0 + r_geom(5对点间结构) 通道
