# P5 坐标系

P5 双身份：**数据协议**（5 landmark + 躯干朝向）与**标准化坐标系**。
本文定义后者；数据结构见 `p5.py`。

## 标准 P5 帧

```
        +z
        │      ● head
        │   ╱  │  ╲
        │ 手   │   手
        │ ╱    │    ╲
        └──────┼───────→ +x  (躯干朝向)
       ╱       │
   左踝●───────●右踝          ↑ 原点 = 踝中点
      +y 朝向躯干左方（图中向内）
```

| 要素 | 定义 |
|---|---|
| 原点 | 左右踝中点（`ankle_mid`） |
| `+x` | 躯干朝向（torso forward） |
| `+y` | 躯干左方 |
| `+z` | 竖直向上（重力对齐） |
| `torso_yaw` | ≡ 0（帧由躯干定义，恒为零） |
| 单位 | 米 / 弧度 |

**没有绝对水平位置、没有绝对 yaw**——标准帧表达的是
"机器人以自身为参照的姿态"，不是"在世界哪里"。

## torso_yaw 语义

`torso_yaw` = 躯干朝向与**所在帧** `+x` 轴的夹角（rad，±π）。

| 所在帧 | yaw 值 | 含义 |
|---|---|---|
| 标准 P5 帧 | ≡ 0 | 定义使然 |
| P5Clip 统一帧 / 世界帧 | 实际值 | 5 点阵推不出朝向，yaw 补这个信息缺口 |

## 帧约定：P5 帧无关

`P5` 对象本身**不声明所在帧**——坐标系约定归持有方：

- 单独的 P5：默认视为标准帧（yaw 应为 0）
- `P5Clip.frames`：**全部帧共用同一坐标系**（坐标统一，
  每帧 yaw 携带该帧相对朝向）

`standardize()` 把任意帧下的 P5 归一到标准帧：
踝中点 → 原点，绕 z 旋转使 yaw → 0。只做平面刚体变换，
无缩放。

## 与相邻类型的帧关系

| 类型 | 帧语义 |
|---|---|
| `Pose.anchor(...)` | 把无位置姿态解析进任意帧（P5 帧是特例 `ankle_mid`） |
| `SupportGeometry/State` | 帧无关；`SupportPlan` 统一首帧 P5 系 |
| `P5Clip` | 全序列共享一帧；首帧通常即标准 P5 帧 |

## 不变量

- `standardize()` 后 `torso_yaw == 0`，踝中点 `== (0,0)`
- 变换保模长/保形状——只换参照系，不改姿态
- `pos` 索引稳定（`POINT_NAMES` 序），具名字段与索引双通道
