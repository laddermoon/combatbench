# P5 坐标系

```
        +z
        │
        │      ● head
        │   ╱  │  ╲
        │ 手   │   手
        │ ╱    │    ╲
        └──────┼───────→ +x
       ╱       │
   左踝●───────●右踝   原点=踝中点
```

| 要素 | 定义 |
|---|---|
| 原点 | 左右踝中点 |
| +x | 躯干朝向 |
| +y | 躯干左方 |
| +z | 竖直向上 |
| 单位 | 米 / rad |

无绝对位置、无绝对 yaw——表达"以自身为参照的姿态"。
