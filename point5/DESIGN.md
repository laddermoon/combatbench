# Point5 (P5) — 业务动作语言设计

> 版本：v2（躯干朝向局部系）。v1 世界绝对坐标系已废弃。

## 1. 定位

P5 是**与仿真器无关的业务层动作语言**。人（或高层战术规划模型）只设定
稀疏的"五个点"来表达动作意图；下游各层（领域模型的插值平滑、重建
模型的姿态反解、质心动力学、控制器）负责把 P5 变成可执行动作。

P5 层只表达**几何意图**：位置、朝向关系。不含速度、力、关节细节。

## 2. 五个点

| 点名 | 语义 |
|---|---|
| `head` | 头部中心 |
| `hand_right` / `hand_left` | 手部中心 |
| `foot_right` / `foot_left` | 脚踝中心 |

## 3. 局部坐标系

**P5 状态 = `local_pos[5×3]`，仅此而已。** 无绝对位置、无绝对朝向、
无独立 yaw 字段。

坐标系由**躯干朝向**定义：

```
原点 O = 双脚脚踝 XY 中点（Z 原点 = 地面 z=0）
X 轴   = 躯干前向
Y 轴   = 躯干左侧
Z 轴   = 上
```

双脚相对躯干的姿态自由：踝线在局部系中不必然与 Y 轴重合。

世界放置（站哪、面朝哪）不是姿态的属性，是消费时的选择。

## 4. Clip：关键帧 + 坐标转移链

```
Clip = keyframes[]
每帧 = { p5: local_pos[5×3],
         transfer: {dx, dy, dyaw, dur} }   # 第一帧无 transfer
```

第 k 帧的 `transfer` 记录**本帧的局部坐标系在上一帧局部系里的位姿**：

```
F_k = F_{k-1} ∘ T(dx, dy, dyaw)
dx, dy = 本帧原点在 F_{k-1} 中的 XY 位移（米）
dyaw   = 本帧躯干朝向相对上一帧的转角（度，逆时针为正）
dur    = 上一帧 → 本帧的时长（秒）
```

- **记录在到达帧上**：第一帧没有 transfer，其后每一帧必须有。
- `dyaw` 不可从两帧局部数据推导（局部系内部看不到世界旋转），必须
  作为数据存储。

## 5. 退化情形

- **双脚重合**（踝中点 < 阈值）：原点退化，无法定义局部系——不合法。

## 6. 序列化

### 状态帧

```json
{"type": "p5.v2",
 "p5": [[x,y,z]×5]}            // 顺序 = head,hand_r,hand_l,foot_r,foot_l
```

### Clip

```json
{"type": "p5clip.v2",
 "name": "...",
 "keyframes": [
   {"p5": [[x,y,z]×5]},
   {"p5": [[x,y,z]×5],
    "transfer": {"dx": 0.15, "dy": 0.0, "dyaw": -30.0, "dur": 0.4}},
   ...]}
```

## 7. v1 → v2 变更对照

| v1 | v2 |
|---|---|
| 世界绝对坐标 5×3 | 躯干朝向局部系 5×3 |
| `torso_yaw` 字段 | 消失 |
| Keyframe 含 anchor 规格 | Keyframe = local p5 + transfer |
| durations 数组 | transfer.dur 逐段记录 |
| 世界位置是姿态属性 | 世界放置是消费端的选择 |
