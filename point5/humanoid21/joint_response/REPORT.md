# 关节响应能力分析（Joint Response Authority）

> 问题：控制周期给一个关节目标角度，能不能真的到？
> 结论先行：**静态上"能否到"由杠杆权威决定**（负载侧 com
> 相对关节轴的最大可持水平偏移）；**动态上"多快到"由 PD
> 二阶响应决定**——50ms 控制周期短于多数承重关节的 settle
> 时间，动作要跨多个周期才能表达完。
>
> 复现：`PYTHONPATH=. python3 point5/humanoid21/joint_response/analyze.py`

## 判据

- **杠杆权威** `d_max = τ_max / (m_load·g)`：负载侧 com 对关节轴的
  水平偏移超过它 → 静态撑不住，什么动作目标都白搭。
  - 腿关节 stance 负载 = 全身 − 该腿子树（上游）；swing 负载 =
    该腿子树；腰/臂恒为下游子树。
  - 双腿分摊静不定，按对称载 ≈ 各半（表列单腿为保守上界）。
  - lever 取负载 com→关节锚点在**垂直于关节轴**方向的分量
    （与轴平行的偏移不产生该轴力矩）；竖直轴（z/yaw）直立时
    无重力负载，只受速度限制。
- **PD 响应** `ω_n=√(KP/I)`，`ζ=KD/(2√(KP·I))`：ζ<1 欠阻尼振铃；
  settle ≈ 4/(ζω_n)（欠阻尼）或 3·KD/KP（过阻尼主导极点）。

**对 action 语义的意义**：50ms 控制周期 < 多数承重关节的
settle 时间——单控制周期内关节只能走一小段，"设了目标角"
≠"到了目标角"；要表达完整位移需跨周期持续同向目标（或
sequence/多 knot 决策）。

## 回答原问题

- **深蹲膝伸直**：双膝蹲时膝 req ≤64<80——能撑起来；单腿深蹲在
  0.8–0.9 负载率边缘，再深或带速度就守不住。
- **踮脚尖（踝）**：做不到，结构性的——踝权威 5.1cm < 脚尖
  杠杆 16.7cm，全重压脚时目标角只是愿望。
- **什么时候"设了也到不了"**：负载侧 com 对关节轴的水平偏移
  > τ_max/(m·g) 时，静态上就输了——与目标动作无关。
- **什么时候"能到但慢"**：负载内但 ζ<1 的关节（腰、髋）振铃
  settle ~0.5–1s，单控制周期只走一小步。

## 对 action_for_balance / 代理模型的用法

- 踝通道：τ_ankle 权威 = ±5.1cm COP（单腿）——已是 lip_analyze
  预算同源量；
- 目标偏移→稳态力矩：持续 τ 需求对应目标偏移 Δθ=τ/KP——踝
  KP=100 时 5cm COP 偏移 ≈ Δθ=2 rad ≈ 归一化动作 ~1.0（e2e 中
  |Δa| 0.3–0.6 的来源）；
- 弱关节白名单：静态校验动作目标时，abdomen/hip_x 大角度
  偏移在承重位形下直接判不可达，省掉 oracle 空转。
