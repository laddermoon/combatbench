# Executor：P5 通用伺服控制器目标与方案

> 状态：设计草案，尚未实现完整闭环。用户意图见 [bootstrip.md](bootstrip.md)。
> 本文区分确定的接口要求与可以尝试的算法，不将现有原子能力视为完整控制器。
> 第一阶段的可执行任务分解见 [EXECUTOR_PHASE1_PLAN.md](EXECUTOR_PHASE1_PLAN.md)。

## 1. 项目目标与原则

给定 `Humanoid21Current` 和 P5 指令缓存，持续生成下一周期的 `Action`。
面向 Humanoid21 的通用底层控制，不绑定拳击；动作模仿可通过提取 P5 序列接入。
外部可在任意控制周期刷新指令。没有刷新时继续执行；任务耗尽或显式清空后，
自动收势，到合适的平衡姿态静止，并持续抵抗扰动。

- **大逻辑优先**：简单几何、粗质量模型、有限候选与力学检查；不追求全局最优，
  也不要求有解必能找到。近似参考必须基本自洽，失败必须明确报告。
- **P5 表达意图**：不要求调用者指定精确时间或动力学；时间由控制层安排。
  现有 `Transfer.dur` 仍是正数必填字段，旧采样器会消费它；新控制器应把执行
  时间表单独维护，不能未经处理就把占位时长当成可达时间。
- **职责分层**：P5 核心提供通用几何/质量代理；本目录处理本体、支撑、状态反馈
  和动作生成。未来可让 RL 学习这些参考或执行经验，当前先建立可检查的仿真闭环。
- 五点不能保留原动作全部细节；接触、脚掌方向、节奏等必要语义需逐步补充。
  ASAP/TAKETIME、STOP/PASS、REF/AIM 是拟扩展标注，不是当前已实现的契约。

## 2. 指令契约：第一帧必须锚定当前状态

**调用者提交新指令或重新规划时，P5Clip 第一帧必须等于本次
`Humanoid21Current` 提取出的 P5。此条件是强制接收条件。**

- 起点不一致就拒绝该提交；不自动补过渡、不偷偷替换第一帧，不重置机器人状态。
  数值比较只允许约定的浮点/序列化误差，不允许借容差接纳不同姿态。
- Current 与新 Clip 必须对应同一状态快照；可尝试状态版本号检查，过期提交退回调用者。
  起点相同不代表后续可执行，仍需规划检查。
- P5 为躯干朝向局部系：原点是双踝 XY 中点，Z 原点是地面。
  第一帧无 transfer；后续帧的 transfer 记录本帧局部系相对上一帧的位姿。
  接收时由 Current 提供第一帧世界放置，再沿 transfer 链解析未来目标。
- 当前 `P5Clip` 构造器只校验结构，不知道 Current；上述锚定检查由伺服接收层实现。

**没有新提交时，一致性由跟踪系统维护，不要求调用者反复重新规划。**

实际执行后，用实际 CurrentP5 作为内部剩余计划的首帧，维护未完成目标、进度和
剩余坐标转移链。可先保存未来目标的世界位姿，再从新首帧重算 transfer；
不能只替换首帧或世界放置、照抄旧 transfer，导致所有未来目标一起漂移。
允许更新内部配时与参考细分，不得把跟踪误差当成任务已完成。

缓存接口需区分：`KEEP`（不提交，继续执行）、`REPLACE(clip)`（验证后替换）、
`CLEAR`（明确清空，收势保持）。空指令不是零关键帧的 P5Clip，现有 schema 不允许后者。
非法提交应返回错误且不替换原有效缓存。

## 3. 每周期工作流程

```text
Current + 指令缓存 + 内部进度/上次计划
  0 接收验证，或维护剩余序列的当前锚点
  1 提取真实 P5、质心运动及接触状态
  2 粗质心与支撑规划，确定时间/进度
  3 取 CNext，并保留后续短时参考
  4 协调得到 P5Next 及未来参考
  5 可选：生成自然姿态参考/动作搜索初值
  6 仿真 MPC 搜索动作序列，仅执行第一步
  7 读取真实结果，更新进度；无剩余任务则收势保持
```

### 0. 接收与锚定

**注意事项：**严格遵守第 2 节；同一局部 P5 不代表相同速度，速度来自 Current。
新指令覆盖未来意图，不能覆盖真实运动状态。

**尝试方向：**快照版本、原子验证/替换；保存未完成关键帧的世界目标与事件编号，
从实际首帧重建剩余链，避免重复执行、跳过目标或目标漂移。

### 1. 提取实际状态

**注意事项：**规划起点使用真实质心位置、速度和角动量，不使用 P5 代理代替实测。
统一世界系、单位和采样时刻；root 速度不等于质心速度。

**尝试方向：**复用 `adapter.point5_from_view` 和
`mocap.humanoid21.centroidal_dynamics.state.CentroidalStateExtractor`，
读取 `C=(c,v,L)`（线动量除总质量得到 v），同时记录实际足部接触。
恢复仿真需包含环境/对手条件及影响预测的内部状态；验证恢复与重放的一致性。

### 2. 质心运动、支撑与时间规划

**注意事项：**P5 质量代理给出未来质心参考，不保证动力学可行；真实起点与代理之间
允许存在偏差。质心模型约束身体运动，但不能单独判断快速手脚动作来不来得及。
当前质心模块已有提取/收支/预测，尚无完整未来规划器。

**尝试方向：**从少量 P5 节点生成粗质心目标，结合支撑阶段安排卸载、摆动、落地。
先用固定的少量接触候选；由摩擦、可用支撑力/力矩估时，再检查末端速度/加速度。
候选时长不满足就有限次调整或拒绝；延时不能修复几何/静态承载冲突。
第一版可用平地保守范围；动态运动不能一概要求质心投影始终在支撑多边形内。
接触规则应独立于拳击任务，后续扩展手撑、腾空等支撑类型。

### 3. 提取下一帧目标与预测窗口

**注意事项：**`CNext` 至少含位置和速度，必要时含角动量目标/范围与接触阶段。
只看下一帧容易忽略后续落脚或刹车；PASS 与 STOP 的终端条件不同。

**尝试方向：**以控制周期 Δt 采样，返回 `CRef[1:H]` 和统一时间表，
`CNext=CRef[1]`。窗口尽量覆盖下一关键事件，或添加可收势的终端条件。
姿态、速度和接触参考统一对齐动作结束时刻。

### 4. CurrentP5 + P5NextAim + CNext → P5Next

**注意事项：**从质心反推五点不是唯一映射，任意 CNext 也不一定与指令兼容。
不能为了追踪代理质心，擅自改变 AIM 或移动支撑脚。

**尝试方向：**以共同进度 s 为主要变量，沿剩余 P5 路线生成 P5Next，
以质心规划校核其推进速度；必要时在允许的 REF 范围内做少量几何调整。
冲突时优先调整时间/候选支撑，仍不满足则明确报告。
在世界系固定支撑脚；用平滑曲线展开位置并求导生成速度。
STOP 只约束指定点相对指定参照物的停止，不自动要求全身停住。

### 5. 可选姿态参考 Humanoid21RefNext

**注意事项：**`solve_equilibrium` 是无重几何/弹簧姿态补全，不保证平衡或一帧可达；
当前也不接收实际姿态作为连续性条件，第二阶段可能改变躯干 yaw。

**尝试方向：**对关键节点求解并缓存，作自然形态软偏好和 PD 目标搜索初值。
尝试结合 Current 选择连续解；检查 `satisfied`、关节限位与实际五点误差。
不必强制跟踪完整关节姿态，更不应给每个参考帧虚构零速度。

### 6. 通过 MPC 生成 Action

**注意事项：**现有 Action 是归一化关节 PD 目标，不是直接力矩。
`reclip` 的原评分以完整 CoreState 距离为主，不能直接等同于 P5/质心评分。
其低 root 高度惩罚也可能与下蹲冲突。串行采样仿真是否实时，需要测量。

**尝试方向：**借鉴 `reclip(horizon>1)` / `solve_action_window` 的滚动窗口与
上一轮动作序列前移，改用五点位置/速度、真实质心运动、支撑及自然姿态软代价。
对代理量给容差，对明显失控/非法接触单独判定；搜索失败不标记任务完成。
先离线验证，再尝试较少候选、动作分块或围绕初值搜索低维修正。

### 7. 反馈、缓存耗尽与空指令

**注意事项：**根据实际结果推进并维护首帧一致性，不能用预测状态冒充实测。
空指令不等于冻结当前五点；摆脚或前冲期间可能必须先落脚、减速。

**尝试方向：**在缓存接近耗尽时即安排收势，选择附近可保持的自然平衡姿态，
让速度和角动量趋近零。持续反馈保持；受到扰动时允许必要的调姿/补步。
新指令到来仍须通过第 0 步。规划失败应明确返回状态，并采用经验证的保持/恢复
策略；恢复能力与通用动作能力一样需要逐步验证，不能默认已经具备。

## 4. 现有资源与落地顺序

- 已有：`mechanics.py` 的 P5 姿态补全；`../mass_model.py` 的粗质心/惯量代理。
  代理默认参数曾参考 Humanoid21，既有调参结果不是任意姿态的精度保证。
- 可复用：质心状态/外力/短时预测，以及 `mocap/humanoid21/clip/reclip.py`
  的仿真动作搜索。惯量代理暂作诊断，不直接当作精确动力学模型。
- 建议顺序：先验证缓存契约与稳定保持 → 固定支撑下的短动作 →
  单次接触切换 → 执行中刷新与空指令收势 → 更广动作模仿及 RL 接入。
- 验收分别记录：起点拒绝是否正确、内部首帧是否一致、世界目标是否漂移、
  五点/质心跟踪误差、脚滑与失衡、结束后稳定性、重放误差及每周期计算耗时。
  仿真可重放不等于任务完成；测试动作应覆盖站立、下蹲、伸手、迈步等，而非只有出拳。
