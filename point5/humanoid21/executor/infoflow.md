# Executor 信息流总图

> 三种信息形态：**P5**(几何意图) / **Pose**(精确姿态) / **SupportState**(支撑语义)。
> 帧约定：SupportPlan 全部统一在**首帧 P5 系**存绝对值。

```
┌──────────────────────── 算法1 · 开局一次 ─────────────────────────┐
│                                                                  │
│  Observation ──► f12 ─► ┌ I1.lm  当前支撑态（实测力覆盖）          │
│       │                 └ I2     当前动量 (com_vel, ang_mom)       │
│       │                            │                             │
│  P5Clip ───────► f3 ─► I3  逐帧支撑态 [P5→Pose→anchor(Base帧)]    │
│                                  │                             │
│                          f4(I1,I2,I3) ─► R = SupportPlan ◄───────┘
└──────────────────────────────────┬───────────────────────────────┘
                                    │ SupportPlan（统一首帧 P5 系）
                                    ▼
┌──────────────────────── 算法2 · 每控制步 ─────────────────────────┐
│                                                                  │
│  obs ─► Pose ─► ┬ I4 当前姿态            plan[0] ──► I6 当前支撑态 │
│                 │                          │                     │
│   plan ─► f1 ─► │ I2 锚点P5 ─clip.p5[for_frame]                    │
│           f4 ─► │ I8 本步支撑态目标 (I6/I7/I9 内部)                │
│                 │     │                                            │
│            f2 ─►│ I3 本步目标P5   f3 ─► I5 目标Pose               │
│                 │     │                          │                │
│                 └───► f5(I8, I5) ─► R: Action (21,) ─► 物理步      │
└──────────────────────────────────────────────────────────────────┘
```

## 关键不变量

| 约定 | 说明 |
|---|---|
| **Pose 是唯一枢纽** | obs→Pose→P5/LM/动量，无旁路 |
| **帧统一** | SupportPlan 全在首帧 P5 系；每控制步的 obs 解码在当帧局部系 |
| **状态语义来源** | I1/I6 用**实测力**（obs[52:54]），I3/plan 用**声明意图**（clip 脚 z） |
| **无状态** | Executor 每调用全量重算，plan 不跨步缓存 |

## 数据流语义

```
I1.lm ──┐                          （当前态：实测）
I2    ──┤─► f4 ─► SupportPlan     （规划：声明+推导）
I3    ──┘   （逐帧几何变换）

plan  ─► I7/I9 ─► f4 ─► I8        （锚点链 → 本步目标）
I1+I2+I8 ─► f2 ─► I3 ─► f3 ─► I5 ─► f5 ─► Action
```

`f3` 的转换链（信息形态文档）：
`clip.p5[i] → Pose.from_p5 → support_state_on_p5_axis → _to_base(mid_i,yaw_i)`
