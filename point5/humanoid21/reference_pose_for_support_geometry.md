# reference_pose — SupportGeometry → Pose 单阶段反解设计（第一版）

目标：< 100ms。手段同 infer_from_p5：标准帧内把反解配成
**"少量硬约束 + 先验优化目标"的非线性最小化**，
LM 求可行 → KKT 沿解流形抛目标，解析雅可比直接解。

与 infer_from_p5 的根本区别：**约束信息少得多**——P5 五点把
全身吊住，这里只有"双脚 + 质心"两个锚点（9 标量），上身
（头/腰/臂）几乎全靠优化目标给形。所以本问题里先验/目标
从配角变主角。

输入：SupportGeometry（标准帧）——com(3) + 左右踝心 xy(2+2)
+ 左右踝抬升高度(1+1) + torso_yaw。
踝心 3D = (foot_xy, ANKLE_Z_PLANTED + foot_height)。
输出：Pose（qpos 21 + root_position + root_orientation）。

过程：
0. 先把 SupportGeometry 转成标准几何（踝中点 XY 原点、yaw=0）。
1. 单阶段求解：pitch/roll + 全 21 关节，满足双脚踝心−质心
   相对向量 6 个等式；目标 = 头离质心越远越好（+正则项）。
   解不出来则几何不可达。
2. root_position = 目标 com − 模型 com；root_orientation =
   解出的 pitch/roll + 输入 yaw。
3. 构造标准 Pose，再 _se2 反变换回原帧。

## 决策变量与约束

**变量：pitch, roll + 21 个关节归一化值 = 23 个。**

| 变量 | 数量 | 说明 |
|---|---:|---|
| pitch, roll | 2 | 躯干相对水平面的俯仰/侧倾；yaw 常量=0 |
| 腰 3 + 腿 8 | 11 | 与 infer_from_p5 阶段一相同（_S1_IDX） |
| 踝 4 | 4 | 对踝心位置不可见，但移动 foot 质心，故保留为变量 |
| 臂 6 | 6 | 不固定、靠强先验项拉住（见目标） |

**硬约束：6 个标量。**

| 约束 | 标量数 | 含义 |
|---|---:|---|
| 右踝心 − 模型质心 = 目标右踝心 − 目标质心 | 3 | 右脚相对 com 的向量一致 |
| 左踝心 − 模型质心 = 目标左踝心 − 目标质心 | 3 | 左脚相对 com 的向量一致 |

用相对向量而非绝对 pin：平移自由度被消去，root 事后由
com 绝对位置一行恢复（与 B 方案同构）。
23 变量 − 6 方程 = 17 维解流形，由下面的目标函数选点。

**质心定义（硬数据）**：com = Σ_b m_b·xipos_b / M，
`BODY_MASS` 常量表（battle_circular_v2.xml 导出，单台 40.844 kg）。
com 雅可比闭式：`J_com[:,j] = (M_sub/M)·axis_w×(com_sub−anchor_w)`，
sub = 该关节所在 body 的子树（含自身与全部后代）。

## 优化目标（第一版选定）

```text
min  E(v) = −w_h·|head − com| + E_spring(qn)
              + Σ_arm w_a·(qn − qn_ref)²
```

| 项 | 角色 |
|---|---|
| **max ‖头 − com‖** | 主目标：尽量伸展，等价于把上体从 com 支点尽量顶开 |
| 弹性能 E_spring | 正则：压住无约束自由度（hip_x、abdomen_z、踝等）在自然值，防边界奇异解 |
| 臂强先验 Σ(qn−q_ref)² | 臂基本固定在一个标称格斗姿态 q_ref，但仍允许极端情况下让位 |

## 主目标的已知行为（记录在案）

`com` 被硬约束钉死 ⇒ `max|头−com|` = 把上体杠杆往**任意方向**
甩到最伸，不带"向上"偏好：

- 直立叠加态 |头−com| ≈ 0.53 m，**不是**范数最大解；
- 躯干前平甩（跳水式）可达 ~0.6+，腿后摆补 com——
  范数意义上更优，但形态怪异；
- 故 `E_spring`/臂先验不是可选装饰：没有正则，解大概率落在
  甩躯干到近水平的边界姿态。

备选变体（v1 出怪相时替换）：`max head_z`——头−com 只取
竖直分量，自带"向上"方向语义，预测形态 = 腿当减震器、
脊柱当旗杆。以及"com 在双踝+头平面内"的侧向平衡软项
（注意 com 硬约束下它是常数，只在 com 降级软目标时有意义）。

## 初值（沿用几何估计套路）

- 骨盆估计 = com + (0,0,−0.08)；踝−骨盆向量 → 余弦定理膝角、
  方向估髋角（同 infer_from_p5，PELVIS_DROP 换 COM→骨盆偏移）
- 躯干倾斜初值 = com−踝中点 向量的偏角
- 直膝变体 + 两级确定性扰动 + rad0 + norm0 序列兜底

## 失败语义

阶段一多初值后残差仍超 tolerance ⇒ 几何不可达，与
infer_from_p5 一致（reference 只承诺"合理姿态"，不掩盖矛盾输入）。

## 计数与求解性质

| 量 | 值 |
|---|---:|
| 决策变量 | 23 |
| 硬约束 | 6（踝−com 相对向量） |
| 解流形 | 17 维，由目标函数选点 |
| 求解 | LM 可行段 + KKT-QP 目标段，eval 预算共享，<100ms |

com 对全部 21 关节有非零雅可比列（臂/踝也挪质心），
变量全收——这点和 infer_from_p5 阶段一（11 关节）不同，
不要照搬 _S1_IDX 子集。
