# step_transition — 步到步转移模型（可达阈 + 接力映射）

目标：把"下一步往哪落"从几何问题还原为**可行集 ∩ 意图**
的最优化问题。一个步周期 = 连续摆相 + 离散接力相；
走路 = 接力映射 S 的迭代序列。三种消费意图（建立平衡 /
扇面接力 / 到达目标）共享同一可行集、只差评分。

货币单位：SupportState（com + 双脚位/足高 + yaw +
com_vel + ang_mom）。

## 连续相 — 单支点倒立摆

摆点 = 贴地踝心；绕其转动方程（每轴独立近似）：

```text
θ̈ = g·sinθ/d⊥ + α_踝,   |α_踝| ≤ τ_bound/I_e
    I_e = m·d⊥² (+ e·J·e),   τ_bound = min(τ_act, N·margin)
```

**d⊥ = com 到转轴（过摆点的水平轴）的垂直距离**——不是
到踝心的距离。这是"摆长"的准确定义：

- α_踝 上界与角位置 θ 无关，只随 d⊥ 变（∝ 1/d⊥²）；
  com 沿轴滑动 |d| 变 d⊥ 不变 → 界不变。
- α_重力 = g·sinθ/d⊥ 随 θ 变——正上方为零、水平到顶，
  且 ∝ 1/d⊥（摆越高重力发散越"懒"）。

踝是 2-DOF 铰：只有前后/侧向两力矩轴，**无 yaw 通道**。
输入界恒定 + 扰动随 sinθ 单调增长——这个结构让可达阈
可解析化。N 动力学上随竖直加速度波动，分析取 N=mg
静态近似；刚体 J 按冻结惯量用（慢变二阶量）。

实现：`drift(alpha)` 积分连续相；`lip_analyze` 给每轴
α 界；`capture_point`/`capture_point_at` 给 ξ 及预测。

## 可达阈 — 每个支点自带的可行核

```text
Φ(u) = 平衡核 ∪ 接力核

平衡核：ξ = com + v·τ ∈ COP 可达域
        （ξ̇ = ω(ξ−c) 可被域内 COP 反转 → 不挪脚可收敛）
接力核：ξ 出界但 ∃ 落点 p 使落地捕获成立
        （扇面非空——见下）
```

COP 可达域因模式而异（can_balance 实现）：

| 支撑 | COP 可达 | 机制 |
|---|---|---|
| 单脚 | ±min(τ_act, N·margin)/N ≈ 5cm | 踝矩搬 COP（执行器限 < 鞋底缘）|
| 双脚 | 支撑多边形全长（垂直踝轴） | 载重分摊，不占踝矩 |

**扇面**：落点 p 可行 ⟺ `|p−pivot| ≤ R_eff(T_s)`
∧ `|ξ(T_land) − p| ≤ reach_新`。ξ(t) 沿发散方向指数
跑远，能接住的区域张开成朝发散方向的扇——张角由
发散速率×摆脚时长决定，外缘被腿长截断。扇面收敛
为空 = 迈步也救不回的不可逆边界（time-to-no-capture
本身是有用诊断量）。

平衡核 ⊂ 接力核；can_balance 判的是前者。真实走路
**每一步都在接力核里**——平衡是接力序列停在"下一
扇面恰在当前支点内"的退化情形。

## 离散接力相 — 支点切换映射

落地瞬间 com 连续，pivot u₀ → u₁（候选落点 p）：

```text
推出   v' = v + Δv_push      旧摆残余踝权最后一次花掉
       |Δv_push| ≤ j_max      ——冲量界 push-off

吸震   v⁺ = v' − (v'·d̂₁)d̂₁   新摆建立 = 非弹性约束
       （沿新摆杆方向的速度分量被吸收，垂直保留）

新态   d₁ = com − u₁,  θ̇₁ = v⁺_切向/d⊥₁
```

两个耦合通道互补：

- **吸震 = 新摆入场成本**：落点离发散方向越远、新摆杆
  与 v 夹角越大，损失越多；
- **推出 = 旧摆离场贡献**：预先把 v 掰向吸收最少的方向
  （步态能量学里 push-off 减冲的经典机制）。

同一踝权预算花两次：摆动期持续 α + 离地瞬间冲量。
接力映射 `S: (state, p, Δv_push) → state'` 收全状态，
可行性 = 序列中每态落在某支点可达阈内。

## 三种消费意图

| 意图 | 硬条件 | 评分 | 格斗语义 |
|---|---|---|---|
| 建立平衡 | 落地后新态入平衡核 | ξ 落进新 COP 域越深越好 | 出拳前定步——拳要稳定基座 |
| 扇面接力 | 落地后新态扇面非空（viability 深度 1 前瞻） | 下一扇面朝向 aim 的张角/剩余进度 | 追击/移动——每步不必平衡 |
| 到达目标 | aim 落点 ∈ 可行集 | 可行直落，否则投影最近 | 闪避到指定站位 |

多步序列由外层循环调用单步优化器涌现，不做全局
步态规划。

## 已知简化 — 摆长调制（v1 忽略，记录在案）

实际摆长 d⊥ 可调：膝屈/腿伸缩改变 com 到轴垂距。
量级：com 高 ~0.85m，膝屈可降 0.15–0.25m ⇒ d⊥
变 ~±20–30%，进而：

| 通道 | 灵敏度 | 效应 |
|---|---|---|
| 重力发散率 g·sinθ/d⊥ | ±20–30% | 短摆更难控、长摆更"懒" |
| 踝权上界 ∝1/d⊥² | ∓30–50% | **下蹲增强踝控**——蹲姿策略本模型表达不了 |
| ξ 时标 τ=√(l/g) | ±10–15% | 扇面张角随之伸缩 |

更大的洞不在灵敏度而在**整条径向通道缺失**：
腿伸/屈是沿摆杆方向的第二个控制输入——

- **落地吸震**：真实系统靠膝屈柔顺吃掉冲击，刚性
  非弹性模型把被吸收分量计作纯损失（偏保守）；
- **推出**：腿伸展（提踵/膝伸）的径向冲量是人类
  步态的主要能量注入，远超踝切向 push-off。

v1 取舍：固定 d⊥ + 刚性吸震律。代价是预测系统性
偏难（实际落地更柔、能量账更宽松）——对规划是
安全方向的误差。v2 把伸缩自由度和柔顺吸震引入
接力映射。

## 未决项

- 摆脚时长 T_land：v1 固定（~0.25s）作参数；v2 进
  决策变量（早落 ξ 漂少但可达域小，真权衡）。
- 接力 viability 前瞻深度：v1 深度 1（落地即死的伪
  可行点已排除）；更深收益递减、成本指数。
- j_max 推出冲量界：待标定（踝权预算的一次性冲量
  化，与持续 α 共享预算的换算未定）。
- 双脚贴地时的抬脚选择：放选择器外层——抬 ξ 侧
  还是抬远离 aim 侧。
