# 踝关节力矩极限报告（倒立摆模型）

任务：把机器人看作以踝关节为摆动中心的倒立摆，求踝关节能给机器人
的最大力矩——它是重心高度的函数。分单脚（含左右倾覆）与双脚；
先理论，再实验验证。

## 模型参数（battle_circular_v2.xml）

| 量 | 值 | 来源 |
|---|---|---|
| 质量 m | 40.84 kg | mass_model → N = mg = 400.7 N |
| 踝执行器 τ_act | **±20 N·m/轴** | `<motor>` gear=20, ctrl∈[-1,1]，直驱型 |
| 脚板支撑域 | x∈[-0.097, +0.167]，y∈[-0.047, +0.047] | 双胶囊 r=0.027 |
| 踝轴 | ankle_y=俯仰，ankle_x=侧翻（轴1 0 .5） | XML joint axis |

## 理论

绕踝轴的可用恢复力矩受两个上限约束：

```
τ_eff = min( τ_act ,  N·margin )
```

- 执行器限：恒 20 N·m，与 h 无关
- 支撑限：N·margin —— 脚底 CoP 移出 patch 边界前能提供的对地力矩

### 单脚（N = 全重 400.7N）

| 方向 | margin | N·margin | τ_eff = min(20, ·) | 受限于 |
|---|---|---|---|---|
| 俯仰前（脚尖） | 0.167 | 66.9 | **20** | 执行器 |
| 俯仰后（脚跟） | 0.097 | 38.9 | **20** | 执行器 |
| 侧翻（左右倾覆） | 0.047 | 18.8 | **18.8** | **支撑** |

→ 侧翻是单脚最弱方向，且**被支撑限死**（脚板窄）。

### 双脚（N=400.7N 分摊）

| 方向 | margin | τ_eff |
|---|---|---|
| 俯仰 | 0.167（联合支撑域脚尖线） | 系统级 66.9；单踝仍 ≤20 |
| 侧翻 | sep/2 + 0.047（联合支撑域外缘） | ≈ N·(sep/2+0.047)，约 30-50 |

### 重心高度函数

踝力矩本身不含 h；它的**等效 COM 力/可恢复倾角**才是 h 函数：

```
F_max(h) = τ_eff / h          — 质心高度处最大水平推力
θ_max(h) = asin(τ_eff / mgh)  — 可恢复的最大静态倾角
```

h 越高，同样力矩的等效力越小、可恢复角越小 → 蹲姿天然更稳。

## 结论

- 单脚最薄弱环节是**侧向**：τ_eff=18.8 N·m，且被 4.7cm 侧缘支撑
  限死，执行器富余用不上——侧向平衡策略上靠迈步/支撑切换补
- 俯仰方向执行器先饱和（20 N·m），脚跟（0.097）比脚尖（0.167）紧
- 双脚侧翻把有效 margin 放大到支撑域外缘（sep/2+0.047）——宽站距
  是侧向稳定性的主要来源
- h 函数：F_max(h)=τ_eff/h、θ_max(h)=asin(τ_eff/mgh)——下蹲把同一
  力矩换成更大的等效推力与可恢复角

### 工程含义（对 F4/F5）

- 侧向 com 偏离的可用恢复力矩只有 ~19 N·m——F4 规划侧移时必须保守
- 等效侧向控制力上限 F_max ≈ 18.8/0.86 ≈ **22 N**（h=0.86 站姿）——
  F5 的残差通道 d 若折算为等效踝力矩不应超此量级
- 脚跟 margin（0.097）< 脚尖（0.167）：后倒比前倾更难救

## 已知测量局限

- MuJoCo 胶囊脚板可"滚动"，倾覆阈值有 ~10-20% 偏差（见最小摆绝对
  值系统性偏低）
- 吊架伺服会吸收部分外加力矩——T_tip 分解含踝阻抗分量，解读时按
  饱和值扣除
- 真实倾覆是动态的：准静态阈值给出的是下界
