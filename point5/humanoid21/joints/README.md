# Humanoid21 关节特性说明

模型来源：DeepMind `model/humanoid/humanoid.xml` 移植（gear/限位/腱
定义逐条一致）；DM 原版是纯力矩控制，本环境在外层套了 PD 位置伺服
（`τ = KP·(θ_t−θ) − KD·θ̇`，截到 ±τ_max）。方向语义见 `JOINTSPEC.md`
及本目录各关节 pos/neg × front/side 图——**轴向反直觉，改姿态前看图**。

## hamstring 腱（实测确认，易踩坑）

`hip_y − knee ≥ −0.6` 是**硬约束**（`limited` tendon 的 range，
`stiffness=0` 只关弹簧不关约束）：髋深屈时膝被强制保持弯曲，
仰卧甩髋实验中膝 PD 给满 80 N·m 也被约束力矩完全对冲。
**髋屈意图必须和膝屈意图一起表达**——`joint_reach_range`
看不见这类跨关节约束，`take_action` 能如实反映。

## 50ms 单步实测位移（仰卧，关节目标打满）

| 关节 | 条件 | 50ms 位移 |
|---|---|---|
| hip_y | 腿摆动（仰卧甩腿） | ~0.125 rad（7°） |
| abdomen_y | 仰卧卷腹（τ=40 全程饱和） | ~0.061 rad（3.5°） |
| 站姿腿关节 | 全身压脚 | 0.001–0.04 rad |
| 手臂 | 自由链 | 覆盖全行程 |

→ 单控制周期位移很小，动作靠**同一 action 连续保持**涌现。

## PD/动作语义注意点

- action = 归一化**位置目标**（±1 ↔ 关节限位），非力矩；
  `Pose.corresponding_action()` 是姿态→action 的闭式映射
- 近限位处可发力矩 ∝ 剩余行程（`KP·(θ_lim−θ)`），末端是
  低权威区；腰/臂 KP 相对 τ_max 极大，大误差下实际就是
  恒力开关
- 腹部 τ=40 相对上躯干负载偏弱（DM 基准原样继承，非笔误），
  含腰腹意图的动作按 0.3s+ 多步规划
- `qfrc_bias` 只含**下游子树**重力矩——腿关节 stance 负载在
  上游侧，别拿它当需求力矩
